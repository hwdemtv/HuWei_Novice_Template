## 安装步骤（3 分钟）

### Step 1｜下载并解压

下载 zip 文件，解压到你喜欢的位置（比如桌面或文档文件夹）。

### Step 2｜用 Obsidian 打开

1. 打开 Obsidian
2. 点击「打开文件夹作为仓库」
3. 选择刚才解压的文件夹
4. 点击「信任并打开」

![[PixPin_2026-08-11_15-22-27.png]]
### Step 3｜启用预装插件（可选，推荐）

为了给您提供"开箱即用"的完美体验，本模板已为您**预先安装**了主题和插件，并**默认启用 8 个插件**（5 个核心 + 更新器、多端同步、AI 助手），打开就能用：

| 默认启用                 | 用途             |
| -------------------- | -------------- |
| **Templater**        | 模板自动填日期        |
| **Dataview**         | 动态生成课程进度表、任务列表 |
| **Calendar**         | 左侧日历面板         |
| **Outliner**         | 大纲拖拽整理         |
| **Minimal Settings** | 配套 Minimal 主题  |
| **Spiral Updater**   | 「检查模板更新」一键升级   |
| **Remotely Save**    | 多端同步（需自行配置网盘，见课程 L05a） |
| **Realclaudian**     | 内置 AI 助手（需自行配置 API Key） |

> [!tip] 已启用 · 内置 AI 助手 Realclaudian
> 仓库预装并**默认启用**了 AI 助手 **Realclaudian**，但需要你配置 API Key 后才能真正工作。**未配置不会报错，也不影响其他任何功能**；暂时不用的话，去 `设置 → 第三方插件` 关闭即可。

> [!note] 为什么有些插件看起来"没反应"？
> 仓库还预装了 **Excalidraw、Tasks、Table Editor、PDF Plus、Style Settings** 等 10 个进阶插件，但**默认未启用**——这是刻意的，避免新手一上来被一堆功能淹没。
> 等你跑通基础流程，去 `设置 → 第三方插件` 按需打开即可。每个插件的用途见 [[00_万法 (开箱即用·Hub)/01_模板/06_外部模板库/使用说明#二、插件说明|使用说明 · 插件清单]]。

如果您在打开时看到了安全提示，只需点击 **「信任作者并启用插件」** 即可一键激活所有功能，无需手动联网下载！

### Step 4｜开始使用

打开左侧的 `📖 开始之前.md`，跟着做 3 件事。

或者，如果你已经熟悉系统，直接打开 `中控台.canvas` 查看可视化仪表盘——包含五区流水线、课程进度、模板库等快捷入口。

## 🔄 版本更新（v1.0.0 起）

模板内置 **互为螺旋·更新器** 插件，装好后无需重新下载完整包，在 Obsidian 里就能一键升级到最新版。

### 怎么更新

命令面板（`Ctrl/Cmd+P`）搜 **检查模板更新**：

- 有新版 → 弹出确认窗（显示更新说明）→ 点「立即更新」
- 已是最新 → 提示「已是最新版本 ✨」
- 想看当前版本 → 命令搜 **查看当前模板版本**

### 会动什么、不动什么

| ✅ 会更新（系统区） | 🚫 绝不触碰（你的数据） |
| --- | --- |
| 模板、课程、第二大脑技能、Claude 指令 | 你所有的笔记（一心 / 二旋 / 三进阶 / 归藏） |
| 仪表盘、主题、CSS 片段 | 自定义模板库、用户画像、长期记忆 |
| | API Key、插件配置、工作区状态 |

每次更新前会**自动备份**被替换的旧文件到 `.更新备份_<时间戳>/`，万一出错可手动还原。

### 常见问题

**Q：我装的是 v1.0.0 之前的旧版，怎么更新？**
A：旧版还没有更新器插件，请**重新下载一次最新的完整包**覆盖安装（或单独装 `spiral-updater` 插件），之后就能自动更新了。

**Q：更新中断了怎么办？**
A：更新是「先备份再覆盖」，中断不会损坏文件。旧文件在 `.更新备份_*` 目录可恢复，重试即可。

**Q：手机上能更新吗？**
A：不行。更新器仅桌面端（Windows / macOS / Linux），和第二大脑 AI 功能一致。

## 🧠 第二大脑 AI 功能（可选·进阶）

> 模板本身不依赖任何 AI，开箱即用。以下功能需要额外配置，适合想获得「知识自动消化+长期记忆+智能召回」体验的用户。

### 什么是第二大脑

在五区架构基础上，内置 8 个 AI 技能：

| 命令               | 功能                     |
| ---------------- | ---------------------- |
| `/init-profile`  | 扫描全库，自动生成你的用户画像        |
| `/digest`        | 消化笔记 → 提炼知识 → 生成候选记忆   |
| `/batch-digest`  | 批量清账 Inbox 积压          |
| `/apply-memory`  | 确认候选记忆 → 归入长期记忆（含矛盾检测） |
| `/ask-vault`     | 智能搜索全库 + 陈旧笔记召回        |
| `/feynman`       | 费曼学习法自测（AI 扮演好奇新手追问你）  |
| `/weekly-review` | 一键生成周回顾                |
| `/vault-health`  | 知识库体检（6 维度评分）          |

### 启用条件

1. **Claude Code CLI**（推荐）或 **Codex CLI** 已安装
   - 安装文档：[Claude Code 官方文档](https://docs.anthropic.com/en/docs/claude-code)
   - 搞不定？微信联系hwdemtv，可付费远程协助配置
1. **Realclaudian 插件已启用**（仓库已预装）
   - `设置 → 第三方插件 → Realclaudian → 启用`
3. **Claudian 设置调整**
   - 打开 Claudian 设置面板
   - `Permission Mode` 改为 `Default`（让写入纪律生效）
   - 填入你的 API Key

### 验证安装

在 Claudian 对话框输入：

```
/init-profile
```

如果 Agent 开始扫描你的库并生成画像，说明一切就绪。

> 📖 完整使用指南见 [[00_万法 (开箱即用·Hub)/07_第二大脑/第二大脑-使用指南|第二大脑使用指南]]

### 写入安全

Agent 的所有写入操作受四道闸保护：
1. **路径权限** — 原始笔记只读，系统目录拒绝访问
2. **候选机制** — Agent 只写候选区，不直接写长期记忆
3. **矛盾检测** — 发现冲突必须你裁决，绝不静默合并
4. **Git 存底** — Claudian Multi-Tab Fork + Git 版本控制，改错可回滚

## 常见问题

**Q：需要什么版本的 Obsidian？**
A：最新版即可。免费软件，去 [obsidian.md](https://obsidian.md) 下载。

**Q：可以在手机上用吗？**
A：可以，但建议先在电脑上熟悉。第二大脑 AI 功能仅限桌面版。

**Q：不用 AI 能用吗？**
A：完全可以。五区架构 + 模板 + 课程不依赖任何 AI，开箱即用。AI 是锦上添花。

**Q：第二大脑 AI 功能需要付费吗？**
A：模板免费。AI 功能需要你自己的 Claude / OpenAI API 额度。Claude Code CLI 安装搞不定可付费远程协助。

**Q：我想加更多模板怎么办？**
A：模板放在 `00_万法/01_模板/` 下，按分类新建即可。

**Q：插件装不上？**
A：检查网络。部分插件需要科学上网。

**Q：购买后遇到问题怎么办？**
支持售后答疑。
