# 📚 我的书架

> 所有 `type: 读书笔记` 的书自动归架，按 **待读 / 在读 / 已读** 分组。点击状态筛选，或搜索标题、作者与分类。

```dataviewjs
const parseDate = raw => {
  if (!raw) return null;
  if (typeof raw.startOf === "function" && typeof raw.toMillis === "function") return raw;
  const parsed = dv.date(raw);
  return parsed?.isValid === false ? null : parsed ?? null;
};
const withoutTemplate = p => !p.file.path.includes("/01_模板/");
const books = dv.pages("#读书").where(p => p.type === "读书笔记").array().filter(withoutTemplate);
// 状态分组口径：对齐模板 status（待阅读/进行中/已完成），兼容 已读/在读 等变体，空值算待读
const statusOf = p => {
  const s = String(p.status ?? "").trim();
  if (/已完成|已读|done/i.test(s)) return "done";
  if (/进行|在读|doing/i.test(s)) return "doing";
  return "todo";
};
const statusMeta = { todo: "⏳ 待读", doing: "🟡 在读", done: "✅ 已读" };
const statusOrder = ["todo", "doing", "done"];
// 排序权重：在读最该盯 → 待读 → 已读；组内按日期倒序
const rank = { doing: 0, todo: 1, done: 2 };
const entries = books.map(p => {
  const st = statusOf(p);
  return {
    page: p,
    status: st,
    cover: p.cover || "",
    date: parseDate(p.finished) ?? parseDate(p.started) ?? parseDate(p.created) ?? p.file.mtime,
    meta: p.author || p.category || "未填写作者"
  };
}).sort((a, b) => rank[a.status] - rank[b.status] || b.date.toMillis() - a.date.toMillis());
const countOf = st => st === "all" ? entries.length : entries.filter(e => e.status === st).length;
const rated = entries.filter(e => e.rating != null && e.rating !== "");
const avgRating = rated.length ? (rated.reduce((s, e) => s + Number(e.rating), 0) / rated.length).toFixed(1) : "—";
const root = dv.container;
root.classList.add("knowledge-shelf-shell");
const el = (parent, tag, cls, text) => parent.createEl(tag, { cls, text });
const link = (parent, path, text) => {
  const a = parent.createEl("a", { cls: "internal-link", text });
  a.setAttr("data-href", path); a.setAttr("href", path); return a;
};

const sidebar = el(root, "aside", "shelf-sidebar");
el(sidebar, "h2", "shelf-brand", "📚 我的书架");
el(sidebar, "p", "shelf-caption", "在读、已读与待读书目");
const nav = el(sidebar, "nav", "shelf-nav");
const stats = el(sidebar, "section", "shelf-stats");
el(stats, "h3", "shelf-side-title", "阅读统计");
[["总书目", countOf("all")], ["🟡 在读", countOf("doing")], ["✅ 已读", countOf("done")], ["⏳ 待读", countOf("todo")], ["⭐ 均分", avgRating]].forEach(([label, value]) => {
  const row = el(stats, "div", "shelf-stat-row");
  el(row, "span", "", label); el(row, "strong", "", String(value));
});

const main = el(root, "main", "shelf-main");
const header = el(main, "header", "shelf-header");
const titleWrap = el(header, "div", "");
el(titleWrap, "h2", "shelf-title", "我的书目");
el(titleWrap, "p", "shelf-subtitle", `共 ${entries.length} 本书`);
const search = header.createEl("input", { cls: "shelf-search", attr: { type: "search", placeholder: "搜索标题 / 作者 / 分类" } });
const filters = el(main, "div", "shelf-filters");
const grid = el(main, "section", "knowledge-card-grid");
let activeStatus = "all";
let query = "";

const render = () => {
  grid.empty();
  const shown = entries.filter(e => {
    const haystack = `${e.page.file.name} ${e.page.author || ""} ${e.page.category || ""}`.toLowerCase();
    return (activeStatus === "all" || e.status === activeStatus) && haystack.includes(query);
  });
  if (shown.length === 0) {
    el(grid, "p", "shelf-empty", "没有匹配的书目。");
    return;
  }
  shown.forEach((entry, index) => {
    const card = el(grid, "article", `knowledge-card cover-tone-${index % 5}`);
    const cover = el(card, "div", "knowledge-cover");
    if (entry.cover) {
      const img = cover.createEl("img", { attr: { src: entry.cover, alt: entry.page.file.name } });
      img.addClass("knowledge-cover-image");
    } else {
      el(cover, "span", "knowledge-cover-icon", "📖");
    }
    el(cover, "span", "knowledge-type", statusMeta[entry.status]);
    const body = el(card, "div", "knowledge-card-body");
    link(body, entry.page.file.path, entry.page.file.name);
    el(body, "span", "knowledge-meta", entry.meta);
    const foot = el(body, "div", "knowledge-card-foot");
    el(foot, "time", "knowledge-date", entry.date.toFormat("yyyy-MM-dd"));
    if (entry.page.rating != null && entry.page.rating !== "") el(foot, "span", "knowledge-rating", `⭐ ${entry.page.rating}`);
  });
};

[{ key: "all", label: "全部" }, ...statusOrder.map(k => ({ key: k, label: statusMeta[k] }))].forEach(({ key, label }) => {
  const button = el(filters, "button", "shelf-filter", `${label} ${countOf(key)}`);
  button.type = "button";
  if (key === activeStatus) button.addClass("is-active");
  button.addEventListener("click", () => {
    activeStatus = key;
    filters.querySelectorAll("button").forEach(b => b.removeClass("is-active"));
    button.addClass("is-active");
    render();
  });
  const navButton = el(nav, "button", "shelf-nav-button", `${label} · ${countOf(key)}`);
  navButton.type = "button";
  navButton.addEventListener("click", () => { button.click(); });
});
search.addEventListener("input", event => { query = event.target.value.trim().toLowerCase(); render(); });
render();
```

> [!tip] 使用说明
> **当前自动收录**：所有 `#读书` 且 `type: 读书笔记` 的书，自动归架。
>
> **新增一本书**：使用 [[00_万法 (开箱即用·Hub)/01_模板/02_理解加工/模板-读书笔记|读书笔记模板]] 创建笔记，填好书名、`author`、`category`、`status`、`started` / `finished`；保存后会自动出现在此处。
>
> **阅读状态分组**：按 `status` 自动分为 ⏳待读 / 🟡在读 / ✅已读；点状态按钮切换查看，`全部` 视图按「在读 → 待读 → 已读」聚簇排序。状态词写 `待阅读 / 进行中 / 已完成`（模板默认）或 `待读 / 在读 / 已读` 均可识别。
>
> **优化卡片信息**：`cover` 填封面图片路径；`rating` 填 1–5 分；未填封面时使用彩色兜底。
>
> **筛选与搜索**：点击状态按钮筛选（全部 / ⏳待读 / 🟡在读 / ✅已读）；右上角按标题、作者或分类搜索；点击卡片打开对应笔记。

> [!info]- 📖 新增一本书：完整流程（点击展开）
> 实例参考：[[20_二旋 (磨一磨·Lab)/《卡片笔记写作法》读书笔记]]
>
> **① 在哪建、怎么触发**
> - 正在读的书放 `20_二旋 (磨一磨·Lab)`；读完归档的移 `40_四归藏`。
> - 在目标目录新建空笔记 → 用 Templater/模板插件插入 [[00_万法 (开箱即用·Hub)/01_模板/02_理解加工/模板-读书笔记|读书笔记模板]]；模板会自动填日期、把光标定位到书名处。
>
> **② 填 frontmatter（书架收录的关键）**
>
> | 字段 | 作用 | 示例 |
> |---|---|---|
> | `type` | ⭐ 书架收录硬条件 1 | `读书笔记` |
> | `tags` | ⭐ 书架收录硬条件 2 | `#读书` |
> | `status` | 阅读状态 | 待阅读 / 进行中 / 已完成 |
> | `started` / `finished` | 起止日期 | 2026-07-01 / 读完填 |
> | `rating` | 1–5 分 | 4 |
> | `author` | 作者，可搜索 | 申克·阿伦斯 |
> | `category` | 分类，按类筛选主力 | 知识管理 |
> | `cover` | 封面图路径，填了显示封面 | `[[纳戒/xxx.jpg]]` |
> | `shelf_type` | 覆盖书架自动分类 | `读书笔记` |
> | `created` | 创建日（自动填），统计依据 | 2026-07-15 |
>
> ⚠️ **`type: 读书笔记` 且带 `#读书` 标签，缺一不上架。**
>
> **③ 填正文（五段式）**
> 一句话总结 → 核心观点（3-5 条）→ 金句摘录 → 我的思考 → 行动清单（`- [ ]` 任务会被 Dashboard 待办区抓取）。
>
> **④ 状态流转**
> `待阅读` ──翻开书、填 `started`──▶ `进行中` ──读完、填 `finished` + 定稿 `rating`──▶ `已完成`
>
> **⑤ 保存即自动上书架**
> 满足 `#读书` + `type: 读书笔记`，保存后立刻出现在本页卡片墙，无需手动归架。
>
> **⑥ 可选优化**
> - **加封面**：封面图丢进 `纳戒/`，`cover` 填 `[[纳戒/xxx.jpg]]`，卡片从彩色兜底升级为真实封面。
> - **`category` 统一口径**：建议固定几个值（如 `知识管理` / `心理学` / `效率`），方便日后按类筛选。
