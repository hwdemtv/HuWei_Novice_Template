# 📚 知识书架

> 从输入到输出，把知识沉淀为可复用的资产。点击类别筛选，或搜索标题、作者与分类。

```dataviewjs
const output = "30_三进阶 (出锅了·Output)";
const archive = "40_四归藏 (存起来·Archive)";
const parseDate = raw => {
  if (!raw) return null;
  if (typeof raw.startOf === "function" && typeof raw.toMillis === "function") return raw;
  const parsed = dv.date(raw);
  return parsed?.isValid === false ? null : parsed ?? null;
};
const withoutTemplate = p => !p.file.path.includes("/01_模板/");
const sources = [
  ["项目复盘", "🔄", dv.pages().where(p => p.type === "项目复盘" || p.type === "复盘三问").array().filter(withoutTemplate)],
  ["文章输出", "✍️", dv.pages(`"${output}"`).array()
    .filter(p => !["📚我的书架", "📚知识书架", "发布清单"].includes(p.file.name))],
  ["归档", "🗄️", dv.pages(`"${archive}"`).array()
    .filter(p => !p.file.name.startsWith("_"))]
];
const unique = new Map();
sources.forEach(([defaultType, icon, pages]) => pages.forEach(p => {
  if (!unique.has(p.file.path)) {
    unique.set(p.file.path, {
      page: p,
      type: p.shelf_type || defaultType,
      icon,
      cover: p.cover || "",
      date: parseDate(p.finished) ?? parseDate(p.published_date) ?? parseDate(p.created) ?? p.file.mtime,
      meta: p.author || p.category || p.platform || "知识资产"
    });
  }
}));
const entries = [...unique.values()].sort((a, b) => b.date.toMillis() - a.date.toMillis());
const types = ["全部", ...sources.map(([type]) => type)];
const countOf = type => type === "全部" ? entries.length : entries.filter(e => e.type === type).length;
const root = dv.container;
root.classList.add("knowledge-shelf-shell");
const el = (parent, tag, cls, text) => parent.createEl(tag, { cls, text });
const link = (parent, path, text) => {
  const a = parent.createEl("a", { cls: "internal-link", text });
  a.setAttr("data-href", path); a.setAttr("href", path); return a;
};

const sidebar = el(root, "aside", "shelf-sidebar");
el(sidebar, "h2", "shelf-brand", "📚 我的知识书架");
el(sidebar, "p", "shelf-caption", "把每一次学习，变成可复用资产");
const nav = el(sidebar, "nav", "shelf-nav");
const stats = el(sidebar, "section", "shelf-stats");
el(stats, "h3", "shelf-side-title", "收录统计");
types.slice(1).forEach(type => {
  const row = el(stats, "div", "shelf-stat-row");
  el(row, "span", "", type); el(row, "strong", "", String(countOf(type)));
});

const main = el(root, "main", "shelf-main");
const header = el(main, "header", "shelf-header");
const titleWrap = el(header, "div", "");
el(titleWrap, "h2", "shelf-title", "全部知识");
el(titleWrap, "p", "shelf-subtitle", `共 ${entries.length} 项知识资产`);
const search = header.createEl("input", { cls: "shelf-search", attr: { type: "search", placeholder: "搜索标题 / 作者 / 分类" } });
const filters = el(main, "div", "shelf-filters");
const grid = el(main, "section", "knowledge-card-grid");
let activeType = "全部";
let query = "";

const render = () => {
  grid.empty();
  const shown = entries.filter(e => {
    const haystack = `${e.page.file.name} ${e.meta} ${e.type}`.toLowerCase();
    return (activeType === "全部" || e.type === activeType) && haystack.includes(query);
  });
  if (shown.length === 0) {
    el(grid, "p", "shelf-empty", "没有匹配的知识资产。");
    return;
  }
  shown.forEach((entry, index) => {
    const card = el(grid, "article", `knowledge-card cover-tone-${index % 5}`);
    const cover = el(card, "div", "knowledge-cover");
    if (entry.cover) {
      const img = cover.createEl("img", { attr: { src: entry.cover, alt: entry.page.file.name } });
      img.addClass("knowledge-cover-image");
    } else {
      el(cover, "span", "knowledge-cover-icon", entry.icon);
    }
    el(cover, "span", "knowledge-type", entry.type);
    const body = el(card, "div", "knowledge-card-body");
    link(body, entry.page.file.path, entry.page.file.name);
    el(body, "span", "knowledge-meta", entry.meta);
    const foot = el(body, "div", "knowledge-card-foot");
    el(foot, "time", "knowledge-date", entry.date.toFormat("yyyy-MM-dd"));
    if (entry.page.rating != null && entry.page.rating !== "") el(foot, "span", "knowledge-rating", `⭐ ${entry.page.rating}`);
  });
};

types.forEach(type => {
  const button = el(filters, "button", "shelf-filter", `${type} ${countOf(type)}`);
  button.type = "button";
  if (type === activeType) button.addClass("is-active");
  button.addEventListener("click", () => {
    activeType = type;
    filters.querySelectorAll("button").forEach(b => b.removeClass("is-active"));
    button.addClass("is-active");
    render();
  });
  const navButton = el(nav, "button", "shelf-nav-button", `${type} · ${countOf(type)}`);
  navButton.type = "button";
  navButton.addEventListener("click", () => { button.click(); });
});
search.addEventListener("input", event => { query = event.target.value.trim().toLowerCase(); render(); });
render();
```

> [!tip] 使用说明
> **当前自动收录**（你产出与沉淀的知识资产）：
> - 🔄 项目复盘与复盘三问（`type: 项目复盘 / 复盘三问`）
> - ✍️ 文章输出（`30_三进阶` 区的成品，排除索引页）
> - 🗄️ 归档（`40_四归藏` 区的沉淀，排除 `_` 开头文件）
>
> **不会收录**：模板文件、目录页、索引页、仪表盘、发布清单，以及 `00_万法` 中的系统预置内容（课程教材、方法论说明、示范案例）——这些用于管理、创建或学习参考，不作为你的知识资产展示。
>
> **新增资产**：
> - 🔄 一篇复盘：用 [[00_万法 (开箱即用·Hub)/01_模板/04_项目复盘/模板-项目复盘|项目复盘模板]] 或 [[00_万法 (开箱即用·Hub)/01_模板/04_项目复盘/模板-复盘三问|复盘三问模板]]，建议补 `category`（领域）、`rating`（经验价值）
> - ✍️ 一篇文章：写进 `30_三进阶` 区即可（如七阶写作模板生成的成品）；填 `published_date` 日期更准
> - 🗄️ 归档资产：把不再活跃的成品移入 `40_四归藏` 区，会自动归到「归档」类别
> - 📖 一本书：改由 [[30_三进阶 (出锅了·Output)/📚我的书架|我的书架]] 收录
>
> **优化卡片信息**（通用）：`shelf_type` 覆盖自动分类；`cover` 填封面图片路径；`rating` 填 1–5 分（书＝推荐分，复盘＝经验价值分）。未填封面时使用彩色兜底。
>
> **筛选与搜索**：点击类别按钮筛选；右上角按标题、作者或分类搜索；点击卡片打开对应笔记。

> [!info]- 📥 新增资产：完整流程（点击展开）
> 知识书架收录三类资产，每类的创建位置与上架条件不同。
>
> **🔄 一、项目复盘 / 复盘三问**
> - **建在哪**：任意工作流目录（`10/20/30/40`）均可——书架**全库按 `type` 扫描**，不依赖位置。
> - **怎么建**：用 [[00_万法 (开箱即用·Hub)/01_模板/04_项目复盘/模板-项目复盘|项目复盘模板]] 或 [[00_万法 (开箱即用·Hub)/01_模板/04_项目复盘/模板-复盘三问|复盘三问模板]] 新建，模板已预置 `type`。
> - **上架条件**：`type` 为 `项目复盘` 或 `复盘三问`（硬条件）。
> - **建议补**：`category`（领域，如 `产品` / `效率`）、`rating`（1–5 经验价值分）、`cover`。
>
> **✍️ 二、文章输出**
> - **建在哪**：必须放 `30_三进阶 (出锅了·Output)` 区（书架按目录扫描该区）。
> - **怎么建**：无专属模板，通常由 [[00_万法 (开箱即用·Hub)/01_模板/03_输出表达/模板-HW-DE-MTV七阶写作模板|七阶写作模板]] 等工具生成成品后保存至此。
> - **上架条件**：位于 `30_三进阶` 且不是索引页（`📚我的书架` / `📚知识书架` / `发布清单` 自动排除）。
> - **建议补**：`published_date`（发布日期，决定卡片显示日期）、`author`、`category`、`cover`。
>
> **🗄️ 三、归档资产**
> - **建在哪**：把不再活跃的成品**移动**到 `40_四归藏 (存起来·Archive)` 区。
> - **上架条件**：位于 `40_四归藏` 且文件名不以 `_` 开头。
> - **注意**：归档区里若有 `type: 项目复盘` 的文档，会被优先归到「项目复盘」tab（`type` 精筛先于目录扫描）；只有**无 `type` 的普通文档**才进「归档」tab。
>
> **🔧 通用规则**
> - 覆盖自动分类：加 `shelf_type` 字段（如 `shelf_type: 项目复盘`）。
> - 加封面：`cover` 填图片路径（如 `[[纳戒/xxx.png]]`）。
> - 加评分：`rating` 填 1–5。
> - 卡片日期优先级：`finished` → `published_date` → `created` → 文件修改时间。
