# 🧠 认知心理学 × 产品设计：系统 1/2 框架的跨领域应用

> 卡尼曼在《思考快与慢》中提出的「系统 1 / 系统 2」，不只是一个心理学概念。
> 它可以成为产品设计师的一把手术刀——帮你诊断用户为什么做出「不理性」的决策。

---

## 📖 先搞懂原概念

**系统 1**（快思考）：自动的、直觉的、几乎不费力的。看到「限时折扣」心跳加速 → 系统 1。

**系统 2**（慢思考）：刻意的、理性的、需要消耗精力的。对比三款产品的参数 → 系统 2。

核心洞察：**人脑默认用系统 1 做决策，只有在系统 1 搞不定时才会启动系统 2。**

---

## 🔗 迁移路径

```
认知心理学                →  产品设计
系统 1（自动/直觉）       →  用户的默认行为路径
系统 2（理性/深思）       →  用户的深度决策时刻
系统 1 容量无限           →  用户可以无限刷短视频
系统 2 容量有限           →  复杂表单会导致用户流失
```

---

## 🛠️ 应用框架：产品设计自检表

在设计任何用户流程时，问自己：

### 你在激活用户的哪个系统？

| 你的设计 | 激活的系统 | 用户体验 |
|---------|----------|---------|
| 倒计时 / 限时折扣 | 系统 1（紧迫感） | 冲动决策，可能后悔 |
| 无限下滑流 | 系统 1（好奇心循环） | 停不下来，事后空虚 |
| 一键授权所有权限 | 系统 1（省力） | 可能泄露隐私 |
| 默认自动续费 | 系统 1（惯性） | 忘记取消，被动扣费 |
| 对比参数表 | 系统 2（理性分析） | 更慢但更满意 |
| 逐项权限说明 | 系统 2（主动选择） | 更安全，更信任 |
| 冷静期提示 | 系统 2（暂停反思） | 减少冲动退货 |

### 核心判断标准

> **短期利用系统 1 → 提高转化率，但损害用户信任。**
> **帮助系统 2 做决策 → 转化更慢，但用户更忠诚。**

---

## 🔮 更多迁移场景

这个框架还可以用在：

- **教育产品**：考试时系统 1 容易出错 → 设计防粗心检查机制
- **健康产品**：系统 1 让人选择即时满足（甜食）→ 设计延迟满足的引导
- **金融产品**：系统 1 让人追涨杀跌 → 设设计冷静期和定投默认选项

---

## 📌 可迁移的行动框架

```
当设计一个用户流程时，
先判断「这个节点用户在用系统 1 还是系统 2」，
如果是系统 1 主导，问自己：「我在利用弱点还是在帮 TA 做更好的决策？」
```
