## 这是什么

**互为螺旋**是一套基于 **费曼学习法** 设计的 Obsidian 知识操作系统（Knowledge OS），专为 **超级个体** 打造。

它不只是笔记模板——而是一条完整的 **知识流水线**：

```
📥 输入 → 🧠 理解 → 🗣️ 讲清楚 → 📤 输出 → 🗄️ 沉淀
 Inbox    Lab      Feynman    Output    Archive
```

73 个模板、14 个预装插件、3 个 AI 工具、23 课系统教程——**解压即用，无需折腾**。

## 3 分钟快速开始

### 1. 下载

[**点此下载 ZIP**](https://github.com/hwdemtv/HuWei_Novice_Template/archive/refs/heads/master.zip) 并解压到任意位置。

### 2. 打开 Obsidian

1. 打开 Obsidian → 「打开文件夹作为仓库」
2. 选择解压后的文件夹
3. 点击「信任并打开」

### 3. 开始使用

打开 `📖 开始之前.md`，跟着做 3 件事。

或者直接打开 `中控台.canvas` 查看可视化仪表盘。
