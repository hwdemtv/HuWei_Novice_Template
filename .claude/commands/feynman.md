# /feynman — 费曼学习法

## 参数
$FILE_PATH: 要检验的笔记路径（默认当前活动文件）

## 流程

1. **读取** `$FILE_PATH` 的全部内容
2. **理解主题**：识别这篇笔记的核心知识点
3. **扮演好奇新手**，围绕内容逐个追问：
   - "你说 XXX，那 XXX 是什么意思？能用大白话讲吗？"
   - "你提到 XXX 和 YYY 有关系，具体怎么影响的？"
   - "如果让你举一个生活中的例子，你会举什么？"
   - "如果去掉 XXX 条件，结论还成立吗？"
4. **挑刺规则**：
   - 用户讲含糊 → "这里我不太懂，你能再具体说说吗？"
   - 用户自相矛盾 → "你前面说了 A，后面又说了 B，这两个好像冲突？"
   - 用户用术语搪塞 → "我不懂这个术语，你能不用行话讲一遍吗？"
5. **追问节奏**：每次只问 1-2 个问题，等用户回答后再追问，不要一次列 10 个
6. **收尾评估**（用户说"结束"或"够了"时）：

```markdown
# 📊 费曼学习法 · 理解完整度评估

## 总分：{X}/10

## ✅ 讲得清楚的部分
- {知识点1}：理解扎实，能用自己的话解释
- {知识点2}：举例恰当

## ⚠️ 讲得含糊的部分
- {知识点3}：依赖术语，缺乏自己的理解
- {知识点4}：存在逻辑矛盾

## 💡 建议
- {针对薄弱部分的具体建议}
```

## 注意
- 纯只读，绝不修改笔记
- 不喂答案，用户不会的地方让他去查，不是直接告诉答案
- 保持好奇心语气，不是考试，是探讨
