# /ask-vault — 问库搜索

## 参数
$QUERY: 搜索问题或关键词

## 流程

1. **解析关键词**：从 `$QUERY` 提取核心关键词和主题
2. **全库搜索**：
   - 文件名匹配（权重 ×3）
   - 标签匹配（权重 ×2）
   - 正文关键词匹配（权重 ×1）
   - 双向链接关联（权重 ×2）
3. **陈旧度排序**：
   - 计算每条命中笔记的最后修改时间
   - 超过 90 天未修改的 → 标 🕰️「许久未碰」+ 额外加权 ×1.5
4. **分组展示**：
   - 🟢 最近活跃（30天内）
   - 🟡 普通相关（90天内）
   - 🕰️ 许久未碰（90天+，优先展示）
5. **输出**：

```markdown
# 🔍 搜索结果：{QUERY}

## 🕰️ 许久未碰（可能有遗忘的知识）
- [📄 标题](路径) — 最后修改：2025-03-15 — 相关度：★★★★☆
- [📄 标题](路径) — 最后修改：2025-01-20 — 相关度：★★★☆☆

## 🟢 最近活跃
- [📄 标题](路径) — 最后修改：2026-07-01 — 相关度：★★★★★

## 🟡 相关
- [📄 标题](路径) — 最后修改：2026-05-10 — 相关度：★★★☆☆
```

6. 如果有 `00_万法/08_长期记忆/` 下的命中，优先展示并标 💎「长期记忆」

## 注意
- 纯只读，不修改任何文件
- 最多返回 15 条结果
- 链接用 Obsidian wiki 格式：`[[路径|标题]]`
