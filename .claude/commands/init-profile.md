# /init-profile — 画像系统初始化

## 流程

1. **扫描全库**：
   - 列出所有 .md 文件（排除 .git/.obsidian/.claude/.claudian/系统目录）
   - 统计：总笔记数、各区分布、标签分布、最近活跃度
   - 构建「主题分布图」（哪些主题笔记最多）

2. **抽样深读**：
   - 从每个区随机抽 2-3 篇笔记（总共 10-15 篇）
   - 分析：写作风格、用词偏好、思维模式、知识领域

3. **生成画像草稿**：

### 文件1：用户画像.md
```markdown
---
title: 用户画像
created: {日期}
updated: {日期}
tags: [系统/画像]
---

# 👤 用户画像

## 基本信息
- 知识领域：{从笔记推断的主要领域}
- 笔记总量：{N} 篇
- 最活跃区：{哪个区笔记最多}

## 推断特征
- 身份/角色：{学生/职场人/研究者/创作者...}
- 关注主题：{Top 5 主题}
- 知识结构：{偏实操/偏理论/偏创作}
```

### 文件2：工作模式.md
```markdown
---
title: 工作模式
created: {日期}
tags: [系统/画像]
---

# ⚙️ 工作模式

## 笔记习惯
- 捕获方式：{碎片灵感/长文/会议记录...}
- 加工偏好：{喜欢改写/喜欢重组/喜欢费曼}
- 输出频率：{每周N篇成品}

## AI 协作偏好
- 建议风格：{简洁/详细/对话式}
- 帮助方向：{消化/挑刺/扩展/排版}
```

### 文件3：风格偏好.md
```markdown
---
title: 风格偏好
created: {日期}
tags: [系统/画像]
---

# 🎨 风格偏好

## 写作风格
- 语气：{正式/口语/混合}
- 句长偏好：{短句为主/长短结合}
- 结构偏好：{总分总/流水/问答}

## 格式偏好
- 是否用 emoji：{是/否/适度}
- 是否用表格：{是/否}
- 标题层级：{最多到H3/H4}
```

### 文件4：记忆策略.md
```markdown
---
title: 记忆策略
created: {日期}
tags: [系统/画像]
---

# 🧠 记忆策略

## 记忆边界
- 保留：{什么类型的知识值得长期记住}
- 过滤：{什么类型不需要}

## 消化偏好
- 详细程度：{精简摘要/详细提炼/全文重组}
- 冲突处理：{保守(只标记)/激进(建议覆盖)}

## 回顾频率
- 周回顾：{每周提醒}
- 陈旧度召回阈值：{90天/180天/30天}
```

4. **展示画像草稿** → 用户逐条确认/修改
5. **写入** `00_万法 (开箱即用·Hub)/07_第二大脑/profile/`
6. **提示用户**：画像已生成，之后的对话 Agent 会自动读取这些画像

## 注意
- 画像是 Markdown 文件，用户随时可以手动修改
- Agent 不会偷偷改画像，所有更新走确认
- 如果库太小（<10篇笔记），提示用户多写一些再初始化画像
