## 📅 近一年创作热力图

```dataviewjs
const today = new Date(); today.setHours(0, 0, 0, 0);

const prefixes = ["10_一心", "20_二旋", "30_三进阶", "40_四归藏"];
const pages = dv.pages().where(p => prefixes.some(pre => p.file.path.startsWith(pre)));

const pad = n => String(n).padStart(2, "0");
const keyOf = d => `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;

const counts = {};
for (const p of pages) {
  const k = keyOf(new Date(p.file.ctime.toMillis()));
  counts[k] = (counts[k] || 0) + 1;
}

const block = n => n === 0 ? "⬜" : n <= 2 ? "🟨" : n <= 4 ? "🟧" : "🟩";

// 从 52 周前的周一开始(JS getDay: 0=周日..6=周六)
const offsetToMon = (today.getDay() + 6) % 7;
const startMonday = new Date(today);
startMonday.setDate(today.getDate() - offsetToMon - 52 * 7);

const weekdayLabels = ["一 ", "二 ", "三 ", "四 ", "五 ", "六 ", "日 "];
let heat = "";
for (let d = 0; d < 7; d++) {
  let row = weekdayLabels[d];
  for (let w = 0; w < 53; w++) {
    const cell = new Date(startMonday);
    cell.setDate(startMonday.getDate() + w * 7 + d);
    row += (cell > today) ? "◾" : block(counts[keyOf(cell)] || 0);
  }
  heat += row + "\n";
}

const pre = dv.container.createEl("pre");
pre.style.fontSize = "10px";
pre.style.lineHeight = "1.25";
pre.style.overflowX = "auto";
pre.textContent = heat;

dv.paragraph("**图例:** ⬜ 无产出 · 🟨 1-2 篇 · 🟧 3-4 篇 · 🟩 5+ 篇 · ◾ 未来");
```

## 📊 月度产出统计(近 12 个月)

```dataviewjs
const today = new Date();
const folderDefs = [["一心", "10_一心"], ["二旋", "20_二旋"], ["三进阶", "30_三进阶"], ["四归藏", "40_四归藏"]];

const pad = n => String(n).padStart(2, "0");
const buckets = {};
const pages = dv.pages().where(p => folderDefs.some(([_, pre]) => p.file.path.startsWith(pre)));
for (const p of pages) {
  const d = new Date(p.file.ctime.toMillis());
  const ym = `${d.getFullYear()}-${pad(d.getMonth() + 1)}`;
  const found = folderDefs.find(([_, pre]) => p.file.path.startsWith(pre));
  if (!buckets[ym]) buckets[ym] = { "一心": 0, "二旋": 0, "三进阶": 0, "四归藏": 0 };
  buckets[ym][found[0]]++;
}

const months = [];
for (let i = 11; i >= 0; i--) {
  const m = new Date(today.getFullYear(), today.getMonth() - i, 1);
  const ym = `${m.getFullYear()}-${pad(m.getMonth() + 1)}`;
  months.push({ key: ym, label: ym });
}

const rows = months.map(mo => {
  const b = buckets[mo.key] || { "一心": 0, "二旋": 0, "三进阶": 0, "四归藏": 0 };
  const total = b["一心"] + b["二旋"] + b["三进阶"] + b["四归藏"];
  return [mo.label, b["一心"], b["二旋"], b["三进阶"], b["四归藏"], `**${total}**`];
});

dv.table(["月份", "一心", "二旋", "三进阶", "四归藏", "合计"], rows);
```

## 💡 怎么读这张图

- **连续的 🟩🟩🟩** = 高产期,通常是你在深耕某个主题
- **大段 ⬜** = 写作低谷,该 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L15-日常节奏|恢复日常节奏]] 了
- **一心数量持续涨、二旋不动** = 只捕获不加工,该 `/digest` 或推进加工
- **三进阶列稳定有数** = 输出节奏健康,知识在真正"出锅"
