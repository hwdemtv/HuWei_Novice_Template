## 🧩 通用 Prompt 片段（复制即用）

> 日常最高频的提示词，不分工具，直接贴进任意 AI 对话即可。

### 📖 理解 / 总结

**三句话总结**（最快确认一篇笔记讲了什么）

```
请用三句话总结这篇笔记：
第一句：它说的是什么。
第二句：它和什么有关联（链接到我已有的知识）。
第三句：它对我有什么用。
```

**费曼理解检查**（用追问逼出理解盲点）

```
请扮演一个完全不了解「XXX」的人，对我的解释提出 3-5 个追问，
帮我发现理解盲点。基于我的回答，指出我哪里理解错了。
```

**通俗讲解**（把复杂概念讲到高中生能懂）

```
请用最通俗的语言解释「XXX」，假设听众是高中生，不用行业术语。
如果可以，用一个简单的类比来说明。
```

### 🔍 知识提取

**知识缺口分析**（喂多篇笔记，找你没意识到的关联）

```
请扫描以下笔记：[[笔记1]] [[笔记2]] [[笔记3]]
找出它们的共同主题（3-5 个），每个主题涉及哪些笔记，
并建议可以新建什么 MOC（内容地图）。
```

**提取行动项**（从笔记/文章里捞出能做的事）

```
从这篇笔记中提取所有可直接执行的行动项，格式：
- 行动项 | 优先级（高/中/低） | 预计耗时 | 依赖什么
```

### ✍️ 写作 / 检查

**逻辑检查**（让 AI 当苛刻编辑，只挑刺）

```
请检查下面的段落，找出逻辑漏洞或不严谨的地方，直接指出问题点并给修改建议。
不要夸我写得多好，只找问题。
```

**对比分析**（用表格厘清两个概念）

```
请对比「A」和「B」，从核心思想、适用场景、优缺点、哪个更适合新手、能否组合
五个维度，用表格展示。
```

### 🏷️ Obsidian 专属

**标签 / 链接建议**

```
读这篇笔记，建议我：① 加哪些层级标签（如 #领域/子类）；② 链接到仓库里哪些已有笔记。
只给建议，并说明理由。
```

## 🔄 工作流示例

### 费曼法 + AI 写作

```
1. 收集灵感（10_一心）
2. 用费曼学习卡理清核心观点（20_二旋）
3. 用小红书文案炼金术生成 3 个版本（AI 辅助）
4. 人工挑选、修改、润色
5. 发布到对应平台（30_三进阶）
```

### 学术翻译 + 降重

```
1. 粘贴英文段落到学术翻译降重姬
2. 获得翻译结果
3. 用费曼法检查：翻译是否准确表达原意？
4. 需要降重时，切换到降重模式
5. 归档到 40_四归藏
```
