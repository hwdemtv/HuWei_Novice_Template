## 🔄 工作流示例

### 费曼法 + AI 写作

```
1. 收集灵感（10_一心）
2. 用费曼学习卡理清核心观点（20_二旋）
3. 用小红书文案炼金术生成 3 个版本（AI 辅助）
4. 人工挑选、修改、润色
5. 发布到对应平台（30_三进阶）
```

### 学术翻译 + 降重

```
1. 粘贴英文段落到学术翻译降重姬
2. 获得翻译结果
3. 用费曼法检查：翻译是否准确表达原意？
4. 需要降重时，切换到降重模式
5. 归档到 40_四归藏
```
