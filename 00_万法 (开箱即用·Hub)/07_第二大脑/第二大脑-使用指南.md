# 🧠 第二大脑·使用指南

> 8 个 AI 技能，让笔记库从「记下来」进化到「自己长出知识体系」。

---

## 🚀 快速开始

### 第一次使用：初始化画像

在 Claudian 对话框输入：

```
/init-profile
```

Agent 会扫描你的全库，生成 4 份画像文件。之后的每次对话，Agent 都知道你是谁、怎么工作、喜欢什么风格。

### 日常使用：3 个核心命令

| 你想做什么 | 输入什么 | 发生什么 |
|---|---|---|
| 消化一篇笔记 | `/digest` | Agent 提炼知识点 → 生成候选记忆 → 检查冲突 |
| 确认候选记忆 | `/apply-memory` | 展示待确认列表 → 你裁决 → 归入长期记忆 |
| 搜索知识库 | `/ask-vault 关键词` | 全库搜索 → 陈旧笔记优先展示 → 带可点击链接 |

## ⚠️ 写入安全

Agent 的写入受四道闸保护：

1. **路径权限**：原始笔记只读、系统目录拒绝访问、长期记忆弹确认
2. **候选机制**：Agent 只写候选区，不直接写长期记忆
3. **矛盾检测**：发现冲突必须你裁决，绝不静默合并
4. **Git 存底**：Claudian 的 Multi-Tab Fork + Git 版本控制

## 💡 使用建议

### 新手路径（第一周）

1. `/init-profile` — 初始化画像
2. 日常往 `10_一心/` 丢笔记，正常记录
3. `/digest` — 试着消化 1-2 篇
4. `/apply-memory` — 确认候选记忆

### 进阶路径（第二周起）

5. `/batch-digest` — 批量清账积压
6. `/ask-vault` — 搜索时用，替代手动翻文件夹
7. `/feynman` — 学了新东西后自测

### 高手路径（一个月后）

8. `/weekly-review` — 每周回顾一次
9. `/vault-health` — 每月体检一次
10. 调整 `profile/` 下的画像文件，让 Agent 更懂你

## 🔧 自定义

### 修改画像

直接编辑 `00_万法 (开箱即用·Hub)/07_第二大脑/profile/` 下的 4 个文件。下次对话 Agent 自动生效。

### 修改记忆策略

编辑 `记忆策略.md` 里的参数：
- 陈旧度召回阈值（默认90天）
- 消化详细程度（精简/详细/全文）
- 冲突处理方式（保守/激进）

### 添加新技能

在 `.claude/commands/` 下新建 `.md` 文件，按现有格式写流程定义。

## ❓ 常见问题

**Q: Agent 会不会偷偷改我的笔记？**
不会。原始笔记是只读的。Agent 只能写候选区和加工区。长期记忆的每次写入都弹确认。

**Q: 改错了怎么办？**
Claudian 的 Multi-Tab Fork 可以回退。加上 Git 版本控制，任何修改都可撤销。

**Q: 候选记忆积压太多怎么办？**
运行 `/apply-memory`，一次可以处理多条。或者调整 `记忆策略.md`，改成"精简摘要"模式减少产出量。

**Q: 画像不准怎么办？**
直接改 `profile/` 下的文件，或者重新运行 `/init-profile`。
