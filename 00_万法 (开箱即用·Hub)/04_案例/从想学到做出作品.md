# 🚀 从想学到做出作品 · 新领域入门案例

> 想入门一个完全陌生的领域，怎么从「啥也不懂」走到「能拿出一个作品」？
> 这是知识操作系统在「新领域学习」场景下的完整旅程——把 AI 当成学习工程师，用一条流水线把学习过程工程化、文件化、项目化。

> 📌 本案例改编自外部资料《如何使用 Codex 快速入门任何一个领域》，核心心法是：**ChatGPT 负责把知识讲明白，AI Agent 负责把学习过程工程化，而你负责每天完成任务、提交答案、复盘错误。**

---

## 🗺️ 全景地图

```
📥 一心（随手丢）    捕获「我要学这个」+ 一句话锁定范围
     ↓
🔨 二旋（磨一磨）    知识地图找方位 + 费曼卡吃透核心概念
     ↓
🚀 三进阶（出锅了）   做一个最小可行项目，用作品验证掌握
     ↓
📦 四归藏（存起来）   考官式自测 + 复盘，沉淀学习方法
```

下面用「我要学 AI Agent」这个真实场景，走一遍完整流程。

---

## 📥 第 1 站：火种（收件箱）

**文件**：`10_一心\` 新建一条笔记，标题就是领域名。

不是「请教我 AI Agent」——这太宽泛，AI 会给你一篇泛泛说明文。要锁定一个**真问题**：

- 这个领域到底解决什么问题？
- 我 30 天后想拿出什么作品？
- 哪些东西我暂时**不用学**（避免分心）？

**关键动作**：写一张「领域捕获卡」

```
领域名：AI Agent
一句话问题：怎么让 AI 自己规划步骤、调用工具完成任务？
范围边界：暂时不学多 Agent 协作、不学训练原理
30 天目标：做出一个「自动整理资料」的小 Agent
```

> 不要一上来就扎进资料海。先决定「不学什么」，比「学什么」更重要。
> 把领域压缩成三档：**必须先懂的 20%** / 暂时跳过的 60% / 以后深入的 20%。

---

## 🔨 第 2 站：加工（实验室）

**文件**：`20_二旋\` 用两个工具把领域「磨」清楚。

**🎯 知识地图**（先全局，后细节）
- 列出最重要的 20 个核心概念
- 标出概念之间的关系（谁是谁的地基）
- 圈出最容易混淆的几组概念

**📝 费曼卡**（每个核心概念做一张）
- 一句话解释（讲给高中生听）
- 生活类比
- 找到卡壳的地方（⚠️ 这里就是下次要攻的）

**📦 领域压缩卡**：每学完一块，压缩成一张卡保存——一句话解释 + 5 个关键词 + 3 个应用场景 + 2 个常见误区 + 1 道自测题 + 和已有知识的连接。

> 这一站的核心：从「看过很多资料」变成「能用自己的话讲清楚」。
> 讲不清楚的概念，就是没真懂的概念——把它标成 ⚠️，下次回来攻。

---

## 🚀 第 3 站：成品（出锅了）

**文件**：`30_三进阶\` 做一个最小可行项目。

不是「学完再做」——是「边学边做」。用作品验证你是否真的掌握：

```
项目名：自动整理资料的 Agent
一句话介绍：给一个文件夹的资料，自动分类命名
核心功能：……
所需知识点：……
7 天任务拆解：……
验收标准：能运行、能演示、能解释每一步
```

不同领域对应不同的小项目：提示词工程→个人提示词模板库；数据分析→销售看板；写作→选题-大纲-初稿-修改工作流。**项目越小越好，但必须完整**：能运行、能展示、能解释、能迭代。

> 真正掌握一个领域，不是「听懂了」，而是「能做出来」。
> 「听懂了」是最危险的错觉——只有做出来才能戳破它。

---

## 📦 第 4 站：归档（存起来）

**文件**：`40_四归藏\` 做两件事。

**考官式自测**：学完一个阶段，让 AI 切换「严格考官」模式
- 出题（选择 / 概念解释 / 场景应用 / 综合项目），先不给答案
- 评分 + 判断错误类型：**不懂概念 / 不会应用 / 表达不清 / 知识混淆**
- 针对薄弱点给 3 个补救练习

**复盘沉淀**：
- 这次学新领域，哪个方法最有效？
- 哪些卡点重复出现？下次怎么提前规避？
- 沉淀成自己的「学新领域 SOP」

> 归档不是结束，是把「学新领域的能力」本身存进知识网络。
> 下次再入门新领域，直接复用这套流程。

---

## 🧠 关键心法

1️⃣ **先地图，后细节**
一上来扎资料海最致命。先用知识地图建立方位感，再决定学什么、不学什么。

2️⃣ **学习必须工程化**
聊天式学习是问答，项目式学习是系统。把学习过程文件化、项目化、自动化，知识才不会学完就忘。

3️⃣ **能做出来才算学会**
地图 + 概念 + 练习 + 项目，缺一不可。每学一块都要有可交付成果，每个阶段都要有可展示作品。
