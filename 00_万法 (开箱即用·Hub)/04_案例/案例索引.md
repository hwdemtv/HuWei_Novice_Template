> 同一套流程，不同的人用在不同的地方。

## 🗺️ 四条路径，一套流程

```
📥 捕获 → 🔨 加工 → 🚀 输出 → 📦 归档
```

无论你是写文章、备考、做项目还是读书，流程都是一样的。区别只在于：你捕获什么、用什么方法加工、产出什么形式。

## 💡 没有你的角色？

这些案例只是起点。核心逻辑是通用的：

1. **捕获**：把值得做的事记下来（60 秒）
2. **加工**：用结构化方法理清楚（费曼卡 / 复盘三问 / 知识地图）
3. **输出**：整理成可使用的形式（文章 / SOP / 复习地图 / 迁移分析）
4. **归档**：复盘 + 沉淀，为下一个循环积累经验

找到你的场景，走一遍，你就有了自己的案例。
