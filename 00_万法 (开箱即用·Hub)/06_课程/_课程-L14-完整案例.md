## 👀 看：完整案例长什么样

打开 [[00_万法 (开箱即用·Hub)/04_案例/从火种到发布]]，你会看到「效率工具对比」这个话题是如何从一个模糊想法变成一篇归档文章的。

它经过了四个区：

```
📥 10_一心    →  只有标题和一句话
🔨 20_二旋   →  有了核心观点、大纲、草稿
🚀 30_三进阶  →  润色完成，可以发布
📦 40_四归藏  →  已发布，写复盘，存档
```

**现在，你要用自己的话题，走一遍同样的流程。**

> [!note] 💡 课程注释
> 这一课是 Tier 1 的「毕业考试」。如果你能独立走完这四步，说明你已经掌握了这套系统的核心工作流。

## 🧠 解：四步流程回顾

| 步骤 | 区域 | 动作 | 使用的模板 |
|------|------|------|-----------|
| 1. 捕获 | 10_一心 | 60 秒写下一个想法 | 模板-灵感捕获 |
| 2. 加工 | 20_二旋 | 写核心观点 → 大纲 → 草稿 | 模板-加工笔记 |
| 3. 发布 | 30_三进阶 | 润色 + 自检 + 更新发布清单 | 模板-发布清单 |
| 4. 归档 | 40_四归藏 | 写复盘 + 存档 | （自由格式） |

## 🔨 做：完整走一遍

### Step 1｜捕获（5 分钟）

在 `10_一心` 用 [[00_万法 (开箱即用·Hub)/01_模板/01_输入收集/模板-灵感捕获|灵感捕获模板]] 创建一条新火种：

选一个你有话说的话题，比如：
- 「为什么我总是学了就忘？」
- 「XX 工具到底值不值得用？」
- 「我最近发现的一个提高效率的方法」

写下：
1. 一句话说清这个想法
2. 为什么记下来
3. 标签：`#火种`

### Step 2｜加工（20 分钟）

把火种搬到 `20_二旋`，用 [[00_万法 (开箱即用·Hub)/01_模板/02_理解加工/模板-加工笔记|加工笔记模板]]：

1. **核心观点**：一句话说清这篇文章要表达什么
2. **大纲**：3-5 个要点
3. **正文草稿**：从大纲展开，每段 2-3 句话

### Step 3｜发布准备（10 分钟）

把草稿复制到 `30_三进阶`：

1. 润色标题（让它更有吸引力）
2. 用七阶自检清单检查（Heart·Will·Dare·Evolve·Manifest·Transfer·Vault）：
   - [ ] **H**（Heart 情绪）：前三句有没有情绪？
   - [ ] **W**（Will 认知）：有没有打破认知？
   - [ ] **D**（Dare 核心）：核心观点一句话能说清吗？
   - [ ] **E**（Evolve 质疑）：回应质疑了吗？
   - [ ] **M**（Manifest 行动）：有可执行的东西吗？
   - [ ] **T**（Transfer 位移）：认知有位移吗？
   - [ ] **V**（Vault 钩子）：有钩子吗？
3. 更新 [[30_三进阶 (出锅了·Output)/发布清单|发布清单]]

### Step 4｜归档（5 分钟）

把发布版复制到 `40_四归藏`，在末尾加一段复盘：

```markdown
## 📦 复盘

**这次写作的收获：**
-

**下次可以改进的：**
-

**可复用的经验：**
-
```

> [!check] ✅ 验证清单
> - [ ] `10_一心` 里有一条你的火种
> - [ ] `20_二旋` 里有对应的加工笔记
> - [ ] `30_三进阶` 里有润色后的发布版
> - [ ] `40_四归藏` 里有归档版 + 复盘
> - [ ] `发布清单.md` 已更新
> - [ ] 你完整走了一遍「火种→草稿→成品→归档」
