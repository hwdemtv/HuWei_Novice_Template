## 👀 看：为什么 AI + Obsidian 是学习流水线

很多人把 AI 当问答机器，把 Obsidian 当记笔记工具。分开看，各自都有短板：

| 单独用 | 短板 |
|---|---|
| AI | 一次性聊天：今天讲明白，明天就忘，知识不留痕 |
| Obsidian | 空仓库：结构再漂亮，没有内容流动就是摆设 |

合在一起，短板正好互补：

- **AI 的优势**是即时——讲概念、出题、批改、扮演考官、把一堆资料压缩成一张卡片。
- **Obsidian 的优势**是持久——每一次回答、每一张卡片、每一道错题都落成文件，文件之间用双链连成网络，越积越厚。
- **第二大脑**让 AI 读得懂你的库——先扫描全库生成画像，之后每次对话都知道你是谁、学到哪了、薄弱点在哪。

这就是 AI+Obsidian 和普通聊天式学习的分水岭：

> **AI 对话负责把知识讲明白；Obsidian 负责把学习过程工程化、文件化、连接化；第二大脑让 AI 越用越懂你。你只负责每天完成任务、提交答案、复盘错误。**

## 🧠 解：一条从「火种」到「作品」的主线

学一个新领域，走完同一条路径：

```
火种捕获 → 知识地图 → 费曼卡 → 最小项目 → 考官自测 → 复盘沉淀
 10_一心    20_二旋   20_二旋   30_三进阶  40_四归藏   40_四归藏
```

对应到你的五区，就是 **丢进来 → 磨一磨 → 出锅了 → 存起来**。

下面是这条主线上最关键的四个动作，每个都附一段可直接贴给 AI 的提示词（以「AI Agent」为例，换成任何领域都行）。

### 动作 1｜领域捕获卡（火种）

不要问「请教我 AI Agent」——太宽泛，AI 会回你一篇泛泛说明文。要锁定一个**真问题**。在 `10_一心` 新建笔记，把这段贴给 AI：

```
我要入门一个新领域：AI Agent。
请帮我生成一张「领域捕获卡」，存进 10_一心（收件箱）。
包含：1)一句话问题  2)小学生也懂的一句话定位
3)范围边界（哪些暂时不学） 4)30 天想拿出的作品
5)学习压缩三档：必须先懂的 20% / 暂时跳过的 60% / 以后深入的 20%
输出 Markdown，打 frontmatter 标签 #火种 #新领域。
```

> 让 AI 做「压缩领域」而不是「堆资料」：先决定不学什么，比学什么更重要。

### 动作 2｜知识地图（建立方位感）

最怕一上来扎进资料海。正确顺序：**先看地图 → 再学概念 → 再看案例 → 再做练习 → 最后做项目**。在 `20_二旋` 用「知识地图模板」新建一张，贴这段：

```
请用费曼学习法帮我建立 AI Agent 的知识地图，填进模板。
输出：1)领域解决什么问题  2)小学生也懂的解释
3)最重要的 20 个核心概念  4)概念之间的关系（谁是谁的地基）
5)最容易混淆的 10 组概念  6)从入门到项目的 5 个阶段
7)最小必要知识清单  8)暂时不用学的内容  9)建议学习顺序
```

### 动作 3｜最小可行项目（戳破「听懂了」的错觉）

真正掌握一个领域，不是「听懂了」，而是「能做出来」。在 `30_三进阶` 让 AI 设计项目：

```
请帮我设计一个最小可行项目，验证我是否真正掌握。
领域：AI Agent｜基础：编程初级｜时间：7 天｜目标：可展示作品
输出：项目名 / 一句话介绍 / 核心功能 / 所需知识 /
7 天任务 / 每天成果 / 验收标准 / 展示方式。
不会代码请给低代码方案；要进阶请给升级方向。
```

> 「听懂了」是最危险的错觉——只有做出来才能戳破它。`30_三进阶` 就是专门用来戳破错觉的地方。

### 动作 4｜考官自测（揪出「以为懂了其实没懂」的点）

学习最快的人，不是听得最多的，而是被检测最多的。学完一个阶段，让 AI 切考官：

```
现在你是严格考官。根据我学习仓库的内容，对我做一次阶段测试。
形式：10 选择 + 5 概念 + 3 场景 + 1 综合。
先出题不给答案，我答完再评分，判断每题错误类型
（不懂概念 / 不会应用 / 表达不清 / 知识混淆），
把薄弱点写进长期记忆，重排后续计划，给 3 个补救练习。
```

## 🔨 做：当场跑通最小闭环

别等「全部学完」再动手。现在就花 20 分钟，跑通前三步：

**Step 1**｜挑一个你这阵子想入门的领域（不一定是 AI Agent），在 `10_一心` 新建笔记，贴【动作 1】的提示词，得到领域捕获卡。

**Step 2**｜把捕获卡里「20 个核心概念」拿出来，在 `20_二旋` 用「知识地图模板」建图，贴【动作 2】的提示词。

**Step 3**｜挑图里你最模糊的一个概念，用「费曼学习卡模板」做一张费曼卡（L20 学过的方法）。

> [!check] ✅ 最小闭环验证
> - [ ] `10_一心` 有一张领域捕获卡（带范围边界 + 三档压缩）
> - [ ] `20_二旋` 有一张知识地图（至少 20 个概念）
> - [ ] `20_二旋` 至少一张费曼卡
> - [ ] 这三张笔记之间建立了双向链接

跑通这三步，你的新领域学习项目就有了第一个锚点。剩下的（项目、考官、复盘）边学边做。

## 🎯 变：套用到任何领域

### 通用提示词模板

以后学任何领域，直接套这段（改前两行即可）：

```
我要用 AI+Obsidian 快速掌握一个新领域。
领域：{填写}｜背景：{填写}｜每天时间：{填写}｜目标：{考试/工作/做项目/写文章}

我的仓库是「互为螺旋」五区结构：
10_一心 / 20_二旋 / 30_三进阶 / 40_四归藏 / 00_万法（含长期记忆）

请作为我的领域学习架构师：
1. 10_一心 生成领域捕获卡
2. 20_二旋 生成知识地图
3. 拆 20 个核心概念，各做一张费曼卡
4. 制定 30 天路线（每天 学习+练习+输出+测验）
5. 每次学习后更新进度（写进长期记忆）
6. 每 7 天一次阶段测试
7. 30_三进阶 完成一个可展示小项目
8. 40_四归藏 复盘，沉淀「学新领域 SOP」

学习原则：少讲空话多做任务 / 先全局后细节 / 先能用再深入 /
每天必须有输出 / 所有知识通过练习验证。

请先生成领域捕获卡和知识地图，再给第 1 天任务。
```

### 30 天节奏

每天开始问一句「请根据进度安排今天的学习」；每天结束做一次完整复盘。

```
📥 10_一心：捕获「我要学这个」+ 锁定范围
     ↓
🔨 20_二旋：知识地图 + 费曼卡，把领域磨清楚
     ↓
🚀 30_三进阶：最小可行项目，用作品验证掌握
     ↓
📦 40_四归藏：考官自测 + 复盘，沉淀学习方法
     ↓
   发现新问题 / 新兴趣 ──→ 再次进入循环（互为螺旋，向上升维）
```

### 五系统心法

用 AI+Obsidian 学任何领域，核心是建立五个系统——模板里都有现成的落脚点：

| 系统 | 落脚点 | 解决 |
|---|---|---|
| 知识地图 | `20_二旋` | 不知道这个领域有什么 |
| 术语表 | `08_长期记忆/wiki` | 听不懂专业词 |
| 练习系统 | AI 考官 + 费曼卡 | 我以为懂了，其实没懂 |
| 项目系统 | `30_三进阶` | 学了很多，但不会用 |
| 复盘系统 | `40_四归藏` + 复盘三问 | 学完就忘、错了不改 |
