## 🧠 解：Dataview 的三个核心概念（1:00 - 3:30）

[画面] 显示三种查询类型
[旁白] 「三种查询类型。LIST 是一个列表，想要简单清单时用。TABLE 是一个表格，想显示笔记的多个属性时用。TASK 是待办事项列表，想汇总所有待办时用。」
[字幕] LIST / TABLE / TASK

[画面] 显示 FROM、WHERE、SORT 语法
[旁白] 「两个关键语句。FROM 从哪里找——可以是文件夹也可以是标签。WHERE 满足什么——精确筛选。SORT 怎么排——DESC 倒序新在上。筛选条件用的是笔记的 frontmatter 字段——前面让你认真填的属性在这里兑现了。」
[字幕] FROM 圈范围 / WHERE 筛选 / SORT 排序

## 🔨 做：写出你的 3 个查询（3:30 - 6:30）

[画面] 屏幕录制：输入 LIST 查询代码
[旁白] 「第一个查询：LIST，列出所有火种。FROM #火种，SORT file.ctime DESC。保存后看看，是不是列出了你的火种？」
[字幕] 查询 1：LIST 所有火种

[画面] 屏幕录制：输入 TABLE 查询代码
[旁白] 「第二个查询：TABLE，列出 Lab 里的加工中笔记。TABLE status AS 状态，file.mtime AS 最后修改，FROM Lab 文件夹，WHERE status 不等于空。这一招帮你盯着哪些草稿躺太久没动了。」
[字幕] 查询 2：TABLE Lab 中的草稿

[画面] 屏幕录制：输入 TASK 查询代码
[旁白] 「第三个查询：TASK，汇总所有待办。WHERE !completed，GROUP BY file.link。这是全局待办清单——把散落在各笔记里的待办全捞出来。」
[字幕] 查询 3：TASK 全局待办
