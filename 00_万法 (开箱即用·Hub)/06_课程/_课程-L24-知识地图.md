## 👀 看：知识地图模板

上一课 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L23-AI对手盘|L23]] 你已经学会了用 AI 磨炼思维。现在，让我们把那些散落的洞察连接起来。

打开 [[00_万法 (开箱即用·Hub)/01_模板/07_进阶工具箱/模板-知识地图模板]]，核心是：

```
知识节点名称：____
它是什么？（一句话）→ ____
它和我已知的什么东西有关？
  连接 1：____（关系：____）
  连接 2：____（关系：____）
  连接 3：____（关系：____）
它背后的结构是什么？→ ____
它的迁移场景：→ ____
```

> [!note] 💡 课程注释
> 知识不是仓库，是地图。仓库里的东西堆着不动，地图上的点互相连接——连接越多，理解越深，复利越大。

## 🧠 解：从散点到网络

### 大多数人的知识状态

```
笔记 A    笔记 B    笔记 C    笔记 D
  ·         ·         ·         ·
（各自独立，互不相关）
```

### 知识地图的状态

```
笔记 A ──── 笔记 B
  |            |
  |            |
笔记 C ──── 笔记 D
（连接越多，理解越深）
```

### 连接的类型

| 连接类型 | 例子 |
|---------|------|
| 因果 | 「A 导致了 B」 |
| 类比 | 「A 就像 B 一样」 |
| 对比 | 「A 和 B 的区别是」 |
| 层级 | 「A 是 B 的一个子集」 |
| 迁移 | 「A 的方法可以用在 B 上」 |

> [!tip] 不需要全部用到
> 上面 5 种连接类型是参考，不是清单。挑最自然的 1-2 种来用就够了——**有连接，比连接的类型更重要**。

## 🔨 做：制作你的第一张知识地图

### Step 1｜选 5 个你最熟悉的知识点

从你的费曼学习卡、复盘规则、写过的文章中，选出 5 个最重要的知识点。

### Step 2｜画出它们的连接

用知识地图模板，在 `20_二旋 (磨一磨·Lab)` 新建一张地图：

```
知识点 1：____
知识点 2：____
知识点 3：____
知识点 4：____
知识点 5：____

连接关系：
1 ↔ 2：____
1 ↔ 3：____
2 ↔ 4：____
...
```

### Step 3｜找到迁移场景

对每个知识点问：「这个方法还能用在什么场景？」

### Step 4｜用 Obsidian 双向链接

在你的笔记中使用 `[[双向链接]]`，让 Obsidian 自动建立连接。

打开 Obsidian 的图谱视图（左侧栏的🌐图标），你会看到你的知识网络。

> [!check] ✅ 验证清单
> - [ ] 选出了 5 个核心知识点
> - [ ] 画出了它们之间的连接关系
> - [ ] 找到了至少 1 个迁移场景
> - [ ] 用 `[[双向链接]]` 在笔记间建立了连接
> - [ ] 打开图谱视图看到了知识网络

| 场景 | 怎么用 |
|------|--------|
| 写系列文章 | 先画知识地图，再按连接顺序写 |
| 学新领域 | 把新知识点和已知的连接起来 |
| 教别人 | 知识地图就是你的教学大纲 |
| AI 对话 | 把知识地图喂给 AI，让它发现盲区 |
