# L31 | 73 个模板的正确打开方式

> [!tip] 💡 你将收获
> - 了解 73 个外部模板的分类和用途
> - 学会按需选用模板，而非全部安装
> - 建立自己的模板选用策略

---

## 👀 看：外部模板库

打开 `00_万法/01_模板/06_外部模板库/`，你会看到 27 个分类、73 个模板：

| 分类 | 数量 | 典型模板 |
|------|------|---------|
| 日志 | 18 | 每日/每周/每月/每年日志 |
| 项目 | 9 | 项目管理、OKR、复盘 |
| 课程 | 4 | 课堂笔记 |
| 书籍 | 3 | 读书笔记、文献笔记 |
| 会议 | 2 | 会议记录、每日签到 |
| 追踪器 | 3 | 习惯追踪 |
| ... | ... | ... |

> [!warning] ⚠️ 重要提醒
> **不要全部安装。** 73 个模板不是让你都用的，是让你**按需取用**的。用不到的模板会变成噪音。

---

## 🧠 解：模板选用策略

### 选用原则

| 原则 | 说明 |
|------|------|
| **先用核心模板** | 费曼学习卡、灵感捕获、加工笔记、发布清单 |
| **按场景扩展** | 你最近在做什么？选对应的模板 |
| **不超过 10 个** | 同时使用的模板不超过 10 个 |
| **定期清理** | 用了几次觉得没用？删掉 |

### 按场景推荐

| 你的场景 | 推荐模板 |
|---------|---------|
| 内容创作 | 日志 + 项目 + 文章 + 播客 |
| 学生 | 课程 + 书籍 + 追踪器 |
| 职场人 | 会议 + 项目 + 日志 + 公司 |
| 自由职业 | 博客 + 财务 + 联系 + 追踪器 |

---

## 🔨 做：选择你的模板组合

### Step 1｜盘点你的需求

写下你最近 3 个月最常做的 3 件事：

```
1. ____
2. ____
3. ____
```

### Step 2｜从外部模板库中选 3-5 个

打开外部模板库的使用说明，找到对应分类，选 3-5 个模板。

### Step 3｜复制到自定义模板库

把选中的模板复制到 `00_万法/05_自定义模板库/`，和系统模板分开管理。

### Step 4｜试用一周

用一周时间试用这些模板。不好用的删掉。

> [!check] ✅ 验证清单
> - [ ] 知道外部模板库有 27 个分类
> - [ ] 选出了 3-5 个适合自己的模板
> - [ ] 复制到了自定义模板库
> - [ ] 理解「按需取用」而非「全部安装」

## 🎯 变：自定义模板

当你用熟了系统模板，可以开始创建自己的模板：

1. 在 `00_万法/05_自定义模板库/` 新建 `.md` 文件
2. 加上 frontmatter（type, created, tags）
3. 用 `<% tp.file.cursor() %>` 设置光标位置
4. 用 `<% tp.date.now("YYYY-MM-DD") %>` 自动填日期
