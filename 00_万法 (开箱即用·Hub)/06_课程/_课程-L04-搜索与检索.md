# L04 | 笔记越来越多，怎么一秒找到

> [!tip] 💡 你将收获
> - 掌握 Obsidian 全局搜索的 6 个核心语法
> - 用 `path:`、`tag:`、`file:` 精准定位任意一条笔记
> - 建立你自己的「搜索小抄」，再也不用翻文件夹找东西

---

## 👀 看：三个月后你会遇到的问题

你已经按 L03 的方法捕获了一批火种。一个月后你有 50 条笔记，三个月后 200 条。

这时候你会发现一个新问题：**「我记得我写过这个，但在哪？」**

翻文件夹？太慢。一个个点开看？更慢。

你需要的是**搜索**——记住几个关键词，一秒定位。

按 `Ctrl+Shift+F`（Mac: `Cmd+Shift+F`），打开全局搜索面板。这就是你这节课的主战场。

![[全局搜索面板.png]]

> [!note] 💡 课程注释
> 五区架构解决了「放哪」的问题，搜索解决了「找哪」的问题。笔记越多，搜索比翻文件夹越快。这是从「文件夹思维」升级到「数据库思维」的第一步。

## 🧠 解：6 个最常用的搜索语法

搜索框不只是输入关键词。在关键词前面加几个字母，就能精准筛选。

### 1. 普通关键词：模糊匹配

```
效率
```

搜索所有正文、标题里包含「效率」的笔记。**不区分大小写，按部分匹配**（「高效率」也能搜到）。

### 2. `path:` 按路径（文件夹）搜索

```
path:10_一心
```

只搜 `10_一心 (随手丢·Inbox)` 文件夹里的笔记。`path:` 是**部分匹配**，只打文件夹名的前几个字也能搜到。想看 Inbox 里堆了多少东西？用这个。

### 3. `tag:` 按标签搜索

```
tag:#火种
```

搜所有打了 `#火种` 标签的笔记。**标签是你给笔记贴的隐形分类——一条笔记可以有多个标签，但只能在一个文件夹里。搜索标签比翻文件夹灵活得多。**

### 4. `file:` 按文件名搜索

```
file:复盘
```

只搜文件名包含「复盘」的笔记，不搜正文。找某条特定笔记时最快。

### 5. `section:` 按标题块搜索

```
section:核心观点
```

搜所有「核心观点」这个标题下的内容。想找你写过的所有核心观点？用这个。

### 6. `-`（减号）排除

```
tag:#火种 -tag:#已发布
```

搜所有火种，但**排除**已发布的。减号 = 不要这个。

### 组合：用空格连接 =「且」

```
path:20_二旋 tag:#加工中
```

=「在 Lab 文件夹里，且标签是 #加工中 的笔记」。

> [!example] 速查表
> | 你想找 | 这样搜 |
> |--------|--------|
> | 某个词出现在哪 | `关键词` |
> | 某个文件夹里的 | `path:文件夹名` |
> | 某个标签的 | `tag:#标签名` |
> | 文件名含某词的 | `file:词` |
> | 某个标题下的内容 | `section:标题` |
> | 排除某个条件 | `-tag:#xxx` 或 `-path:xxx` |
> | 多个条件同时满足 | 用空格隔开 |

## 🔨 做：练习 5 个真实搜索场景

打开全局搜索（`Ctrl+Shift+F`），逐个完成：

### 场景 1｜清点你的火种库存

```
tag:#火种
```

看看你现在有多少条火种。如果不到 5 条，回 L03 再补几条。

### 场景 2｜Inbox 里堆了什么没处理

```
path:10_一心 -tag:#火种
```

Inbox 里**不是火种**的笔记——可能是日记、可能是随手记的。该加工的加工，该归档的归档。

### 场景 3｜找出所有「半成品」

```
path:20_二旋
```

Lab 里的草稿，哪些躺太久了？超过两周还没写完的，考虑归档。

### 场景 4｜追一个主题

想一个你常写的词（比如「方法」「AI」「复盘」）：

```
你的关键词
```

看看你在这个主题下已经积累了多少。**这往往是下一篇系列文章的种子。**

### 场景 5｜保存常用搜索

1. 输入 `tag:#火种`
2. 点搜索框右侧的搜索设置按钮（三条横线图标）→ 选择「保存当前搜索」
3. 命名为「🔥 火种库存」

保存后，点击左侧边栏的「书签」面板（书签图标），在「未归类」分组下就能看到已保存的搜索，下次点一下就能调出来。

## 🎯 变：搜索面板的两个按钮

搜索框右侧有两个小按钮：

| 按钮 | 作用 |
|------|------|
| **Aa** | 区分大小写开关，点击切换开/关 |
| **搜索设置**（三条横线图标） | 点击展开搜索语法提示，告诉你 `path:` `file:` `tag:` 等搜索前缀怎么用 |

![[搜索面板的两个按钮.png]]

> [!example] 📌 进阶搜索语法速查
> | 语法 | 作用 | 示例 |
> |------|------|------|
> | `line:词` | 只搜包含该词的**那一行**（长笔记里精确定位） | `line:TODO` |
> | `task:` | 只搜**待办事项**行（`- [ ]` / `- [x]`） | `task:""` 找所有未完成 |
> | `heading:词` | 只搜**标题行** | `heading:核心观点` |
> | `/正则/` | **正则表达式**模糊匹配（最强，但需要点门槛） | `/20\d\d-\d\d-\d\d/` 找所有日期 |
> | `"精确短语"` | 引号包裹 = 精确匹配整句（不拆词） | `"知识管理"` |
>
> 💡 正则举例：`/#\w+/` 找所有标签，`/\[\[.*\]\]/` 找所有双链。需要时再学，不用强记。

> [!tip] 🔄 批量查找替换
> 在搜索面板点「搜索设置（≡）」→ 勾选**「替换」**，会出现替换框。输入旧文本和新文本，就能**跨笔记批量改**（如把所有 `#待办` 统一改成 `#进行中`）。⚠️ 批量替换没有撤销，大批量操作前建议先备份或用 Git。
