# L30 | 从单篇到系列：8 篇路线图

> [!tip] 💡 你将收获

## 👀 看：8 篇系列路线图

打开 [[00_万法 (开箱即用·Hub)/01_模板/07_进阶工具箱/8篇系列路线图]]，你会看到一个完整的系列规划：

```
系列一  认知设计    → 写公众号不是表达，是设计读者的情绪路径
   ↓
系列二  内容引擎    → 好文章不是写出来的，是生产出来的
   ↓
系列三  经验沉淀    → 经验会褪色，方法论不会
   ↓
系列四  能力迁移    → 学一个东西解决十个问题，靠的是结构
   ↓
系列五  知识地图    → 知识不是仓库，是地图
   ↓
系列六  AI 对手盘   → AI 不是代笔，是帮你挑刺的对手盘
   ↓
系列七  系统外化    → 方法论不该活在脑子里，该活在系统里
   ↓
系列八  回到起点    → 你一直在学的不是写作，是认知系统
```

> [!note] 💡 课程注释
> 单篇文章解决一个问题，系列文章解决一类问题。8 篇系列 = 一个完整的认知升级路径。

---

## 🧠 解：为什么要做系列

| 单篇 | 系列 |
|------|------|
| 解决一个问题 | 解决一类问题 |
| 读者看完就走 | 读者追着看下一篇 |
| 每篇独立获客 | 系列自带传播力 |
| 容易灵感枯竭 | 路线图指引方向 |

### 等级系统（Lv.0-8）

路线图里有一个等级系统，每完成一篇就升级：

| 等级 | 对应 | 你做到了什么 |
|------|------|------------|
| Lv.0 | 开始 | 写了第一篇 |
| Lv.1 | 认知设计 | 知道文章是「设计」出来的 |
| Lv.2 | 内容引擎 | 有了持续产出的系统 |
| Lv.3 | 经验沉淀 | 知道怎么把经验变成规则 |
| Lv.4 | 能力迁移 | 学一个能解决十个 |
| Lv.5 | AI 对手盘 | AI 正确参与了思考 |
| Lv.6 | 知识地图 | 知识连成了网络 |
| Lv.7 | 系统外化 | 方法论活在系统里 |
| Lv.8 | 回到起点 | 开始建设下一个循环 |

## 🔨 做：制定你的 8 篇系列计划

### Step 1｜选一个主题

你最擅长/最想分享的一个主题是什么？

### Step 2｜用路线图模板规划

在 `20_二旋` 新建笔记，参考路线图模板，规划 8 篇文章：

```
系列一：____（入门认知）
系列二：____（基础方法）
系列三：____（进阶技巧）
系列四：____（场景应用）
系列五：____（系统思维）
系列六：____（工具辅助）
系列七：____（外化输出）
系列八：____（回到起点）
```

### Step 3｜设计 V→H' 的连接

每篇文章的结尾（V）要连接到下一篇的开头（H'）：

```
系列一 V：「但光知道方法还不够，你还需要一个持续产出的系统——下篇见」
系列二 H'：「上篇我们聊了方法，但你有没有发现：学了就忘？」
```

> [!check] ✅ 验证清单
> - [ ] 选定了一个系列主题
> - [ ] 规划了 8 篇文章的标题和核心观点
> - [ ] 设计了至少 3 处 V→H' 的连接

## 🎯 变：不同规模和不同领域的系列

### 按规模

| 规模 | 适合谁 | 建议 |
|------|--------|------|
| 3 篇迷你系列 | 刚开始做系列的人 | 先跑通 V→H' 连接 |
| 8 篇标准系列 | 想建立个人品牌的人 | 用路线图模板规划 |
| 持续更新系列 | 已有固定读者群的人 | 每月 1-2 篇，长期积累 |

### 跨域迁移：系列不只是写文章

| 系列主题 | 适合谁 | 8 篇路线示例 |
|---------|--------|------------|
| ✍️ 写作方法论 | 内容创作者 | 认知设计→内容引擎→经验沉淀→能力迁移→… |
| 🎓 信号与系统 | 学生 | 时域基础→傅里叶→拉普拉斯→Z变换→系统函数→频域分析→综合应用→考前策略 |
| 💼 项目管理 SOP | 职场人 | 需求管理→进度跟踪→风险管理→复盘方法→团队协作→流程自动化→知识沉淀→持续改进 |
| 📚 认知科学应用 | 终身学习者 | 系统1/2→决策偏误→习惯设计→助推理论→选择架构→行为经济学→跨领域迁移→知行合一 |

> 系列路线图的核心是「V→H' 的钩子连接」——无论写文章、做课程还是规划学习路径，这个结构都成立。
