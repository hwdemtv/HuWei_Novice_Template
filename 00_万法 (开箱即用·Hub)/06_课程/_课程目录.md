## 🎯 新手快速通道：按你的水平选择起点

不用每人都从 L00 开始。对号入座：

| 你的情况               | 推荐起点              | 为什么            |
| ------------------ | ----------------- | -------------- |
| 完全新手，从没碰过 Obsidian | **L00**           | 先建立全局认知，再动手    |
| 装过 Obsidian，但没建过系统 | **L02**（五区架构）     | 跳过软件基础，直接学结构思维 |
| 已有自己的笔记系统，想迁移过来    | **L03**（火种捕获）     | 先把现有想法灌进 Inbox |
| 会写笔记，但找不到东西        | **L04**（搜索）       | 直击痛点           |
| 笔记一堆，互相没联系         | **L05**（双向链接）     | 让笔记长出网络        |
| 只想学写作方法            | **L11**（七阶写作法）    | 核心方法论，可独立使用    |
| 只想学知识沉淀            | **L20**（费曼学习法）    | 进阶玩家的高频入口      |
| 想做自动化仪表盘           | **L25**（Dataview） | 直接上杀手锏         |

> 💡 **建议节奏**：每周 2-3 课，约 8 周完成全部。每课顶部都标了预估时间，可按你的空闲灵活安排。

## 🚧 三个 Tier 里程碑

每完成一个 Tier，你就解锁了一层能力。卡住时回来对照：

- 🎉 **Tier 0 完成**（L05 收尾）→ 能存、能找、能连，笔记不再是孤岛
- 🎉 **Tier 1 完成**（L15 收尾）→ 能独立产出并发布，且有稳定日常节奏
- 🎉 **Tier 2 完成**（L25 收尾）→ 经验开始复利，笔记能查能连能自动汇总
- 🎉 **Tier 3 完成**（L33 结营）→ 拥有完整知识操作系统 + 产品化能力
