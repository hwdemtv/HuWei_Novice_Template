# L01a | Markdown 10 分钟速成

> [!tip] 💡 你将收获
> - 掌握 Markdown 最常用的 10 个语法
> - 能在 Obsidian 里写出排版清晰的笔记
> - 不再被「格式」卡住，专注于「内容」

---

## 👀 看：Markdown 长什么样

你打开仓库里的任何一篇笔记，看到的那些 `#`、`-`、`**加粗**`、`[[双向链接]]`，都是 Markdown。

它不是编程语言，是一种**极简的排版语法**——用几个特殊符号，代替鼠标点来点去的操作。

> [!note] 💡 课程注释
> 你不需要记住所有语法。这篇课程教的是**最常用的 10 个**，覆盖 90% 的日常使用。用到不会的，回来查就行。

---

## 🧠 解：10 个最常用的 Markdown 语法

### 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

`#` 越多，标题越小。日常笔记用 `##` 和 `###` 就够了。

### 2. 加粗和斜体

```markdown
**这是加粗**
*这是斜体*
***这是加粗又斜体***
```

### 3. 列表

无序列表（圆点）：
```markdown
- 第一项
- 第二项
- 第三项
```

有序列表（数字）：
```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 4. 待办清单

```markdown
- [ ] 没做完的事
- [x] 做完了的事
```

在 Obsidian 里可以直接点击勾选。

### 5. 引用

```markdown
> 这是一段引用的话。
```

适合用来标注别人说的话、重要提醒、或自己的感悟。

### 6. 链接

外部链接（网址）：
```markdown
[显示的文字](https://example.com)
```

内部链接（Obsidian 特有，叫「双向链接」）：
```markdown
[[另一篇笔记的标题]]
```

`[[]]` 是 Obsidian 最强大的功能之一——后面会专门讲。

### 7. 图片

```markdown
![图片描述](图片地址)
```

在 Obsidian 里更简单：直接**复制粘贴**图片，自动插入。

### 8. 代码

行内代码（一个词或一小段）：
```markdown
用 `Ctrl+N` 新建笔记
```

代码块（一整段）：
```markdown
​```
这里写一整段代码或文本
​```
```

### 9. 分割线

```markdown
---
```

三个减号，独占一行。用来分隔不同章节。

### 10. 表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

> [!warning] ⚠️ 小贴士
> 手写表格不难，照上面的格式来就行。嫌手写麻烦？直接**右键 → 插入 → 表格**，Obsidian 自带这个功能，不需要装插件。

### 进阶：Callout 提示框 ⭐（全课程都在用，必学）

你看到的这种带颜色、带图标的框，就是 **callout**。写法：

```
> [!tip] 这是标题
> 这是内容，每行前面都要加 `> `。
```

常用类型（换 `[ ]` 里的词即可）：

| 类型 | 感觉 | 什么时候用 |
|------|------|-----------|
| `[!tip]` | 💡 建议 | 你将收获 / 心法 |
| `[!note]` | 📝 注释 | 补充说明 |
| `[!warning]` | ⚠️ 警告 | 注意 / 铁律 |
| `[!check]` | ✅ 清单 | 验证清单 |
| `[!example]` | 📋 示例 | 速查表 / 例子 |

**折叠框**：类型后面加个 `-`，框就**默认收起**，点一下才展开——适合放「可选的深入内容」：

```
> [!info]- 深入（可选）
> 这里放进阶内容，不打扰主线。
```

### 进阶：其他几个好用的

| 语法 | 效果 | 写法 |
|------|------|------|
| 高亮 | ==黄底重点== | `==文字==` |
| 注释 | 编辑可见、预览/导出隐藏 | `%%备注%%` |
| 嵌入图片（限定大小） | 控制宽度 | `![[图.png\|300]]` |
| 嵌入音频 | 笔记里直接播放 | `![[录音.mp3]]` |
| 嵌入视频 / PDF | 内嵌显示 | `![[视频.mp4]]` / `![[文件.pdf#page=1]]` |

## 🔨 做：用 Markdown 写一篇笔记

现在动手试试。在 `10_一心` 新建一条笔记，用刚学的语法写一段内容：

### 练习模板

```markdown
## 今天学到了什么

> 用一句话总结今天最大的收获。

### 三个要点

1. **第一个要点**：简要说明
2. **第二个要点**：简要说明
3. **第三个要点**：简要说明

### 待办

- [ ] 明天要做的事 1
- [ ] 明天要做的事 2

### 灵感

今天想到了一个有意思的事：

> 某某说过一句话：「______」

---

**下一步**：把这条笔记存到 Inbox。
```

照着打一遍。不需要复制粘贴——**亲手打才能记住**。

> [!check] ✅ 验证清单
> - [ ] 会用 `#` 写标题
> - [ ] 会用 `**文字**` 加粗
> - [ ] 会用 `- ` 写列表
> - [ ] 会用 `- [ ]` 写待办
> - [ ] 会用 `>` 写引用
> - [ ] 会用 `[[笔记名]]` 做双向链接
> - [ ] 会用 `---` 画分割线
> - [ ] 亲手写了一篇包含以上语法的笔记

## 🎯 变：Obsidian 的快捷键

Markdown 不需要记太多，因为 Obsidian 帮你加了快捷键：

| 你想做的 | 快捷键          | 效果                 |
| ---- | ------------ | ------------------ |
| 加粗   | `Ctrl+B`     | 自动包裹 `**`          |
| 斜体   | `Ctrl+I`     | 自动包裹 `*`           |
| 插入链接 | `Ctrl+K`     | 自动插入 `[]()`        |
| 插入代码 | `` Ctrl+` `` | 自动包裹反引号            |
| 标题   | `Ctrl+数字`    | 比如 `Ctrl+2` = 二级标题（可在**设置 → 快捷键**中自定义） |
| 待办   | `Ctrl+L`     | 切换待办状态             |

**先用快捷键，用多了自然就记住 Markdown 语法了。**

> [!tip] 自定义快捷键
> 如果某个快捷键跟系统冲突（比如 `Ctrl+数字`），可以去 **设置 → 快捷键** 里改成自己顺手的组合。
