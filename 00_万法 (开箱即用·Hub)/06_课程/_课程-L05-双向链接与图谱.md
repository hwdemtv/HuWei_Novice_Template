# L05 | 让笔记和笔记连起来

> [!tip] 💡 你将收获
> - 掌握 `[[]]` 双向链接的 4 种用法
> - 学会反向链接面板，发现笔记之间的隐藏关系
> - 打开图谱视图，看见你的知识长成网络

---

## 👀 看：散点 vs 网络

点开左侧栏的图谱图标（像几个节点连在一起的那个）。你大概率会看到几个孤零零的点，彼此不连。

![[关系图谱.png]]
这就是**大多数人的笔记状态**：一条一条独立存在，像散落在桌上的纸片。

```
笔记 A    笔记 B    笔记 C    笔记 D
  ·         ·         ·         ·
（各自独立，互不相关）
```

而高手的笔记是这样的：

```
笔记 A ──── 笔记 B
  |            |
笔记 C ──── 笔记 D
（连接越多，理解越深，复利越大）
```

![[L05-01-framework-scattered-to-network.png]]

连接从哪来？从**双向链接**来。

> [!note] 💡 课程注释
> L01a 提过 `[[笔记名]]`。这节课把它讲透。双向链接是 Obsidian 区别于普通笔记本软件的**根本能力**——它让笔记从「仓库」变成「地图」。

---

## 🧠 解：双向链接的 4 种用法

### 1. 基础链接：把两条笔记连起来

```
这个观点我在 [[效率工具对比]] 里详细聊过。
```

`[[效率工具对比]]` 会变成可点击的链接。**关键魔法：另一边的笔记也会自动知道「有谁提到了我」——这就是「反向链接」。**

### 2. 别名：链接显示一个名字，跳到另一个笔记

```
详细见 [[效率工具对比|我那篇爆款]]。
```

读者看到「我那篇爆款」，点击跳到「效率工具对比」。适合用更顺口的措辞指向同一篇笔记。

### 3. 标题引用：链接到某篇笔记的某个小节

```
具体的对比维度，见 [[效率工具对比#核心观点]]。
```

`#` 后面跟标题名。长文章里精确跳转用。

### 4. 嵌入：把一篇笔记直接「嵌」进当前笔记

```
![[效率工具对比]]
```

前面加 `!`，整篇笔记会直接显示在这里。**做仪表盘、汇总页时超好用**——比如在首页嵌入最新的几篇火种，不用复制内容，源笔记一改，嵌入处自动更新。

> [!example] 一图看懂
> | 写法 | 效果 |
> |------|------|
> | `[[A]]` | 链接到 A |
> | `[[A\|显示名]]` | 显示别名，跳到 A |
> | `[[A#标题]]` | 链接到 A 的某个标题 |
> | `![[A]]` | 把 A 整篇嵌入显示 |

## 🔨 做：在你的笔记间建立连接

### Step 1｜打开反向链接面板

1. 打开任意一条笔记
2. 点击右侧边栏的「反向链接」面板

![[反向链接.png]]

   - 没看到？按 `Ctrl+P` 打开命令面板，输入「反向」，选择「反向链接: 显示反向链接列表」

![[命令面板输入反向.png]]

3. 这个面板显示「**谁提到了当前笔记**」
4. 旁边的「出链」面板则显示「**当前笔记提到了谁**」——两个面板是一对，一起看更清楚笔记间的关系

![[出链列表.png]]

### Step 2｜在一条笔记里链接 3 条相关笔记

打开你的一条火种或加工笔记，在正文里手动加 3 个链接：

```
这个想法和 [[另一条笔记]] 有关，
也呼应了 [[第三条笔记]] 的观点，
可以参考 [[第四条笔记]] 的做法。
```

如果被链接的笔记还不存在，`[[新笔记名]]` 会显示成灰色——点击它会**自动新建**这条笔记。这就是「先占坑，后填充」。

### Step 3｜打开图谱视图，调过滤器

1. 点左侧图谱图标，打开全局图谱
2. 试着在图谱顶部的过滤器里输入 `path:10_一心` —— 只看 Inbox 的笔记（过滤器支持 `path:`、`tag:` 等语法，和搜索类似）
3. 鼠标悬停某个点，高亮它的所有连接

### Step 4｜用本地图谱看「单篇笔记的关系网」

1. 打开一条你最重视的笔记
2. 看右下角——如果本地图谱已经打开，直接看就行；没看到的话，按 `Ctrl+P` 输入「局部」，选择「关系图谱: 打开局部关系图」![[局部图谱.png]]
3. 它只显示**和当前笔记相关的笔记**，比全局图谱更聚焦

## 🎯 变：用图谱诊断你的笔记健康

图谱不只是好看，它能**诊断问题**：

| 图谱现象 | 说明什么 | 怎么办 |
|---------|---------|--------|
| 一大片孤立的点 | 笔记之间没连接 | 给相关笔记加 `[[]]` |
| 几个点连成簇 | 形成了知识主题 | 这簇可以写成系列文章 |
| 某个点连了很多线 | 你的核心节点 | 值得展开成深度文章 |
| 完全没有连接 | 还在「记录」阶段 | 进入 Tier 1 学「加工」，加工时自然会产生链接 |

> [!tip] 心法
> 别为了「让图谱好看」而硬加链接。链接应该反映**真实的知识关系**——你在写的时候真的想到了另一篇笔记，才连。
