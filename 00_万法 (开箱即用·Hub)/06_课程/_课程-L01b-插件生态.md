# L01b | 插件全景图：会找、会装、不被插件淹没

> [!tip] 💡 你将收获
> - 分清「核心插件」和「社区插件」
> - 学会自己发现、安装、管理插件，不用每次问人
> - 拿到一份「5 个必装之外」的精选清单
> - 知道怎么换主题，把 Obsidian 调成你喜欢的样子

---

## 👀 看：5 个必装之外，还有什么？

[[00_万法 (开箱即用·Hub)/06_课程/_课程-L01-基础设置|L01]] 已经帮你配好了 5 个必装插件（Calendar / Templater / Outliner / Dataview / Minimal），够你跑起来。

但你迟早会想：「还能加点什么？」

这课就是给你**一张地图**——让你自己能逛插件生态，挑需要的东西，而不被几千个插件淹没。

> [!warning] ⚠️ 先重申 L01 的铁律
> **第一周别再装插件。** 用熟那 5 个再说。这课是给「已经跑顺了、想扩展」的人看的，不是让你现在就装一堆。插件焦虑是 Obsidian 放弃率最高的原因。

---

## 🧠 解：两类插件 + 一份精选清单

### 1. 核心插件（Obsidian 自带，开关即可）

不用下载，「设置 → 核心插件」里打勾就能用：

| 插件 | 干什么 | 什么时候开 |
|---|---|---|
| **白板（Canvas）** | 自由排布卡片/图片/链接，画知识地图 | 做 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L24-知识地图\|L24 知识地图]] 时 |
| **书签** | 收藏常用笔记/搜索/图谱，侧边栏直达 | 笔记多了之后 |
| **文件恢复** | 笔记的历史版本，误删能找回 | **强烈建议常开**，救命用 |
| **大纲** | 侧边栏显示当前笔记的标题结构 | 写长文时 |
| **录音机** | 笔记里直接录音 | 会议/灵感口述 |
| **幻灯片** | 把笔记当 PPT 放映 | 分享/讲课 |
| **工作区** | 保存当前窗口布局，一键恢复 | 固定工作场景 |

### 2. 社区插件（第三方开发，要自己装）

这是 Obsidian 生态的主力。下面是「5 必装之外」值得知道的精选：

| 你想要  | 装这个                                | 一句话                                                               |
| ---- | ---------------------------------- | ----------------------------------------------------------------- |
| 任务管理 | **Tasks**                          | 给待办加日期/优先级/重复，自动汇总                                                |
| 看板视图 | **Kanban**                         | 像 Trello 一样拖卡片，做项目/排期                                             |
| 手绘白板 | **Excalidraw**                     | 画思维导图/流程图，手绘风格                                                    |
| 一键捕捉 | **Quick Add**                      | 不打断当前工作，快捷键捕获灵感                                                   |
| 同步备份 | **Obsidian Git**                   | 免费云同步 + 版本控制（见 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L05a-多端同步\|L05a 同步]]） |
| 多端同步 | **Remotely Save**                  | 免费 WebDAV 同步（见 L05a）                                              |
| 心智图  | **Mind Map**                       | 把笔记大纲一键变思维导图                                                      |
| 表格增强 | **Sortable** / **Advanced Tables** | 表格排序、便捷编辑                                                         |
|      |                                    |                                                                   |
|      |                                    |                                                                   |

> [!note] 💡 课程注释
> 这张表是「**按需自取**」，不是「全部装上」。你有哪个痛点，才装对应的那个。没有痛点，就先不装。

### 3. 主题：把 Obsidian 换成你喜欢的样子

仓库已预装 **Minimal** 主题。想换别的：设置 → 外观 → 主题 → 管理，挑一个评分高的（比如 Berlin、Things、Atom）。颜值舒服了，才愿意天天打开。

---

## 🔨 做：自己装一个社区插件

用 **Tasks** 练手（任务管理几乎人人用得上）：

1. **设置 → 第三方插件**（首次会提示「关闭安全模式」，关掉）
2. 点「**浏览**」→ 搜索框输入 `Tasks`
3. 点「**安装**」→ 装完点「**启用**」
4. 在任意笔记里写：`- [ ] 试试 Tasks 插件 📅 2026-07-01`
5. `Ctrl+P` → 搜 `Tasks` → 看它怎么把任务汇总起来

### 装完之后，学会这三件事

- **关掉不用的**：设置 → 第三方插件 → 关掉开关（不删配置，随时再开）
- **卸载**：插件项旁边「×」（确定不用了再删）
- **更新**：插件偶尔要点「检查更新」，保持新版避免出 bug

> [!check] ✅ 验证清单
> - [ ] 能分清核心插件（自带开关）和社区插件（要下载）
> - [ ] 自己成功装了 1 个社区插件并启用
> - [ ] 会关掉 / 卸载插件
> - [ ] 会换主题
> - [ ] 记住铁律：**没有痛点就不装**，装了不用就卸

## 🎯 变：进阶与排坑

| 情况 | 怎么办 |
|---|---|
| 想装「还没上架商店」的插件 | 用 **BRAT** 插件，填 GitHub 地址安装（测试版/小众插件） |
| 插件装太多，Obsidian 变卡 | 关掉不常用的；插件越多启动越慢、冲突概率越高 |
| 某个插件突然不工作 | 先禁用其他插件排查冲突 → 再检查是否需要更新 |
| 手动安装（离线/公司限制网络） | 把插件文件夹放进 `.obsidian/plugins/` → 设置里启用 |

### 一条不会变的建议

> [!tip] 💡 插件极简主义
> Obsidian 的插件系统强到能让你折腾一个月不写一个字。**先把系统跑顺、产出几篇内容，再回来按需加插件。** 工具是给内容服务的，别反过来。
