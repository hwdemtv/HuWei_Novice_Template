# L22 | 搭建你的内容生产流水线

> [!tip] 💡 你将收获
> - 理解四层内容引擎的架构
> - 把「偶尔写一篇」变成「持续生产」
> - 完成自己的内容引擎搭建清单

---

## 👀 看：内容引擎的四层架构

打开 [[00_万法 (开箱即用·Hub)/01_模板/07_进阶工具箱/模板-内容引擎搭建清单]]，你会看到：

```
第一层：火种仓库（随时收集灵感）
    ↓
第二层：螺旋模具（用 HW-DE-MTV 变成大纲）
    ↓
第三层：模板流水线（AI 做 0→60，你做 60→95）
    ↓
第四层：数据飞轮（发布后记录数据，优化下一篇）
```

> [!note] 💡 课程注释
> 持续输出不靠灵感，靠系统。灵感是火种仓库里的存量，系统是让存量变成产出的流水线。

---

## 🧠 解：为什么需要内容引擎

大多数人的写作模式：

```
灵感来了 → 写一篇 → 发布 → 灵感没了 → 停更三个月
```

内容引擎的目标：

```
火种持续入库 → 模具自动排序 → 流水线生产 → 数据反馈优化 → 火种更多
```

**这是一个飞轮，不是一次性事件。**

### 四层详解

| 层 | 做什么 | 你需要做什么 |
|---|--------|------------|
| 火种仓库 | 随时捕获灵感 | 每天花 5 分钟扫一遍来源清单 |
| 螺旋模具 | 把火种变大纲 | 用 HW-DE-MTV 框架结构化 |
| 模板流水线 | AI 辅助生产 | AI 做初稿，你做关键改写 |
| 数据飞轮 | 发布后复盘 | 记录数据，沉淀到火种仓库 |

### AI 的分工边界

| AI 做 | 你做 |
|--------|------|
| 整理素材 | 判断哪些素材值得用 |
| 生成初稿 | 改写关键段落 |
| 列举观点 | 选择核心观点 |
| 优化措辞 | 决定语气和态度 |
| 提供反驳 | 决定是否回应、如何回应 |

> [!info] 🤖 AI 怎么接进来？
> 上面说的是"AI 帮你做什么"，但 AI 本身不会凭空出现——你需要先完成接入配置：安装 **Claudian 插件**、配置 **API 接口**（Agnes AI / OpenAI 兼容）、设置 **CC-Switch 代理**（模型切换）。
> → 详见 [[00_万法 (开箱即用·Hub)/进阶服务包说明#03 · AI 接入指导|进阶服务包·AI 接入指导]]

## 🔨 做：搭建你的内容引擎

### Step 1｜建立火种来源清单

在你的日记模板或一张新笔记里，写下你日常的灵感来源：

```
我的火种来源：
1. 和朋友聊天时的一个观点
2. 刷到一篇文章，不同意某个点
3. 工作中踩了一个坑
4. 读到一句让你停顿的话
5. AI 对话里出现了一个意外洞察
```

### Step 2｜建立发布节奏

决定你每周/每月发多少内容：

| 节奏 | 适合谁 |
|------|--------|
| 每天 1 条朋友圈 | 想保持社交活跃度的人 |
| 每周 1 篇公众号 | 想建立个人品牌的人 |
| 每月 2-4 篇深度文章 | 想做专业内容的人 |

### Step 3｜用内容引擎模板

在 [[00_万法 (开箱即用·Hub)/05_自定义模板库/README|05_自定义模板库]] 里创建你自己的内容引擎清单，参考模板填写。

> [!check] ✅ 验证清单
> - [ ] 写出了自己的火种来源清单（至少 5 项）
> - [ ] 确定了发布节奏
> - [ ] 理解了四层引擎的逻辑

## 🎯 变：不同场景的内容引擎

内容引擎的四层结构是通用的——「收集 → 结构化 → 生产 → 反馈」，不同场景填入不同内容：

| 你的场景 | 火种来源 | 加工模具 | 产出形式 | 飞轮反馈 |
|---------|---------|---------|---------|---------|
| ✍️ 公众号作者 | 灵感/热点/评论区 | HW-DE-MTV 七阶 | 公众号文章 | 阅读量/分享数 |
| 🎓 学生 | 课堂疑问/作业难题/考试错题 | 费曼学习卡 | 考前复习地图 | 考试成绩/理解深度 |
| 💼 职场人 | 会议/踩坑/重复问题 | 复盘三问 | SOP/流程文档 | 问题复发率/团队采纳度 |
| 📚 终身学习者 | 读书/播客/跨领域洞察 | 知识地图 | 迁移分析/知识图谱 | 新连接发现数 |

> 学生的「火种仓库」是错题本和课堂疑问；职场人的「数据飞轮」是问题复发率。
> 核心逻辑一样，只是零件不同。
