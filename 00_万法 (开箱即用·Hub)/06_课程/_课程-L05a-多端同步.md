# L05a | 把仓库装进手机，选一个方案就够了

> [!tip] 💡 你将收获
> - 搞懂为什么 Obsidian 的同步要「自己解决」
> - 看懂 4 套主流方案的取舍，选出适合你的那一个
> - 在手机上打开你的仓库，随地能记

---

## 👀 看：同步，是 Obsidian 绕不开的一道坎

你迟早会遇到这种时刻：

公司电脑写了一半，回家打开发现没同步；手机上改了一篇，电脑里还是旧版本；两台设备同时编辑同一个文件，仓库里突然冒出一个「冲突副本」。

有人就是因为同步太折腾，放弃了 Obsidian。

原因在它的设计理念——**Local First（本地优先）**：你的笔记本质上就是硬盘里的一堆 Markdown 文件。数据真正属于你（不怕服务关闭、随时能迁移），但代价是：**同步这件事，得你自己解决**。

> [!note] 💡 课程注释
> 这和 Notion、印象笔记正好相反——它们数据在云端，同步是天生自带的。Obsidian 把数据主权还给你，也把同步的责任还给了你。

---

## 🧠 解：4 套方案，选一个就够

| 方案 | 价格 | 移动端 | 冲突处理 | 技术门槛 | 适合谁 |
|---|---|---|---|---|---|
| **官方 Sync** | 付费（约 $48/年） | ✅ | 强 | 低 | 不想折腾、求稳 |
| **iCloud / OneDrive / 坚果云** | 免费/低 | ✅ | 弱 | 低 | 轻量、苹果/微软生态 |
| **Git + GitHub** | 免费 | ⚠️ 要配置 | 强 | 高 | 程序员、技术用户 |
| **Remotely Save + WebDAV** | 插件免费 | ✅ | 中 | 中 | **国内免费首选** |

### 一句话选型

- **完全不想折腾** → 官方 Sync（体验最接近「无感同步」，缺点是要花钱）
- **苹果全家桶** → iCloud（记得关掉「优化存储」，否则文件没下载完会显示空白）
- **国内 + 想免费** → **Remotely Save + 坚果云 WebDAV**（速度好、配置不难，最均衡）
- **有 NAS** → NAS + WebDAV（数据全在自己手里，局域网飞快，长期用户的终极方案）
- **程序员** → Git + GitHub（版本控制最强，但门槛最高，新手别碰）

> [!warning] 🚦 云盘方案的一条铁律
> iCloud / OneDrive / 坚果云 这类云盘，冲突处理都偏弱——两台设备同时改一个文件，会生成冲突副本要你手动合并。所以记住：**不要同时在两台设备编辑同一个文件**。改之前，给云盘一点同步时间。

> [!tip] 💡 选型心法
> 同步没有「最强」，只有「最适合你现在阶段」。**新手先选最简单稳定的一个，让自己真正开始记。** 与其花一周研究同步方案，不如花 10 分钟配好一个能用的，然后去写笔记。

---

## 🔨 做：配好一个能用的

**只选一条路径，别两条都配**——两套方案同时同步同一个文件夹，必冲突。

### 路径 A：官方 Sync（花钱省心，3 步）

1. 订阅 Obsidian Sync（设置 → 账户 → 升级加购）
2. 桌面端和手机端**登录同一个账号**
3. 创建远程仓库 → 连接 → 等同步完成

配置完基本不用再管，像成熟商业产品一样自己跑。

### 路径 B：Remotely Save + 坚果云（国内免费推荐）

1. **装插件**：设置 → 第三方插件 → 浏览 → 搜 `Remotely Save` → 安装启用
2. **坚果云开 WebDAV**：坚果云网页 → 账户信息 → 安全选项 → 添加应用，拿到 WebDAV 地址、账号、**第三方密码**（不是登录密码）
3. **插件里填入**：Remotely Save 设置 → 选 WebDAV → 填上一步的地址/账号/密码 → 连接
4. 手机端 Obsidian 装同一个插件、填同一套配置 → 开始同步

> [!check] ✅ 验证清单
> - [ ] 只选了**一个**方案（没有两套同时跑）
> - [ ] 电脑端正常同步（新增一条笔记，另一端能看到）
> - [ ] 手机端能打开仓库、能编辑
> - [ ] 第一次同步前，已备份过仓库（防意外）
> - [ ] 用云盘的话：记住「不同时编辑同一文件」

## 🎯 变：进阶与换设备

| 你的情况 | 怎么办 |
|---|---|
| 有 NAS（群晖/极空间/飞牛/威联通） | WebDAV 指向 NAS，数据全在自己手里，终极方案 |
| 想要历史版本回滚 | 官方 Sync（自带）或 Git（最强） |
| 想组合使用 | 主力一套同步，另一套只做特定子文件夹或备份——**别同步同一个文件夹** |
| 换了手机/电脑 | 新设备装 Obsidian → 配好同步 → 等文件拉完（官方 Sync 直接登录同账号恢复） |
| 坚果云免费流量不够了 | 升级付费 / 换 NAS+WebDAV / 重要笔记走官方 Sync |

> [!warning] ⚠️ Remotely Save 的一个提醒
> 它是社区维护的第三方插件，存在停止维护的可能。**配好的同时，保留一份备用方案**（哪怕只是定期手动复制仓库到网盘），别把鸡蛋全放一个篮子。
