# L23 | 让 AI 成为你的思维磨刀石

> [!tip] 💡 你将收获
> - 学会使用四级 AI 对手盘 Prompt
> - 把 AI 从「代笔」变成「挑刺专家」
> - 建立自己的 AI 辅助写作工作流

## 👀 看：AI 对手盘的四级 Prompt

打开 [[00_万法 (开箱即用·Hub)/01_模板/07_进阶工具箱/模板-AI对手盘Prompt库]]，你会看到四个级别的 Prompt：

| 级别 | 名称 | 干什么 |
|------|------|--------|
| 基础版 | 文章诊断 | 告诉你「读者为什么不想点开」 |
| 进阶版 | 观点攻击 | 用最强逻辑攻击你的观点 |
| 高阶版 | 盲区探测 | 告诉你「你没想到什么」 |
| 日常版 | 快速挑战 | 每次对话后挑出逻辑漏洞 |

> [!note] 💡 课程注释
> AI 最大的价值不是替你写，而是替你**挑刺**。你写了一篇文章，AI 帮你找到盲区、攻击弱点、补上漏洞——这才是「对手盘」的意思。

---

## 🧠 解：AI 的正确打开方式

### ❌ 错误用法

```
你：帮我写一篇关于 XX 的文章
AI：好的，以下是文章...
你：复制粘贴，发布
```

**问题：你没有思考，AI 也没有挑战你。产出的是 AI 的平均水平，不是你的独特观点。**

### ✅ 正确用法

```
你：我有一个观点：「____」，帮我攻击它
AI：好的，以下是三个反驳角度...
你：第 2 个反驳有道理，我去补一个案例
你：修改后再让 AI 检查
```

**这才是「对手盘」——AI 挑战你，你回应挑战，最终产出更坚固的观点。**

### 分工原则

| AI 做   | 你做     |
| ------ | ------ |
| 提供反驳角度 | 决定是否回应 |
| 找出逻辑漏洞 | 决定如何修补 |
| 列举盲区   | 决定哪些重要 |
| 优化措辞   | 决定语气态度 |

**判断权永远在你手上。**

### 🥪 三明治工作法：人 · AI · 人

把和 AI 的协作想成一块三明治——**你定义问题（上层 20%）→ AI 执行处理（中间 60%）→ 你判断定稿（下层 20%）**。

| 层 | 谁负责 | 干什么 |
|----|--------|--------|
| 上层（20%）| **你** | 定义问题、给上下文、给约束 |
| 中间（60%）| **AI** | 总结、扩写、找漏洞、提角度 |
| 下层（20%）| **你** | 判断、取舍、定稿、负责 |

> [!warning] 边界：什么该交 AI，什么不该
> AI 擅长**信息提炼、找角度、优化措辞**；不擅长（也别全交）**深度思考、价值判断、情感决策**。涉及事实和数据，**一律自己复核**——AI 会一本正经地编造（俗称"幻觉"）。

> [!example] 🧱 Prompt 四要素公式
> 一个好 Prompt = **角色 + 任务 + 格式 + 约束**。
> - **角色**：告诉 AI 它是谁（"你是一个苛刻的编辑"）
> - **任务**：要它做什么（"攻击我的观点"）
> - **格式**：输出长什么样（"列 3 条，每条带理由"）
> - **约束**：边界（"不要客气，直接挑刺"）
>
> 对比：「帮我看看这篇文章」（❌ 太模糊）vs「你是苛刻编辑，找出这篇文章标题和开头的 3 个问题，每条给理由，别夸我」（✅ 四要素齐全）。

## 🔨 做：用 AI 对手盘优化你的文章

### Step 1｜选一篇你写过的文章

从 `30_三进阶` 或 `20_二旋` 里选一篇。

### Step 2｜用基础版 Prompt 诊断

复制这段 Prompt 到 AI 对话中：

```
请以一个苛刻的读者视角，回答这个问题：

如果你在朋友圈刷到这篇文章，你为什么不想点开？

请从标题、开头、核心观点、实用价值四个维度各指出一个问题。
```

### Step 3｜用进阶版 Prompt 攻击

```
我现在有一个判断：「（粘贴你的核心观点）」

请你完全站在反方立场，用最强的逻辑攻击这个观点。

要求：
1. 不要客气，直接指出漏洞
2. 每个攻击都要给出理由
3. 最后告诉我：这个观点最脆弱的地方在哪？
```

### Step 4｜根据反馈修改文章

把 AI 的攻击当作「质检报告」，逐条回应：
- 有道理的 → 回去补案例/数据
- 没道理的 → 在文章中提前反驳（[[_课程-L11-七阶写作法|HW-DE-MTV 的 E 阶段]]：回应读者质疑）

### Step 5｜（可选）让 AI 住进 Obsidian：Copilot 插件

上面是把 Prompt 贴到网页版 AI 里用。更进一步——装 **Copilot** 插件，就能在笔记里**直接唤起 AI**，不用来回切换窗口。

> [!info]- 深入（可选）：Copilot 配置速查
> 1. 设置 → 第三方插件 → 浏览，搜 `Copilot` 安装并启用
> 2. 进入 Copilot 设置填 **API Key**（推荐 DeepSeek，注册送 500 万 Token，够个人用几个月）
>    - ⚠️ **API Key 安全**：别写进笔记、别传 GitHub、别截图分享——它是你的计费凭证
> 3. 三种上下文模式按需切：
>    - **Current Note**：AI 只读当前笔记（总结/改写单篇）
>    - **Vault QA**：AI 读**整个仓库**后回答（如"我哪些笔记讲过 GAP？"）——首次会建索引，几百篇约几分钟
>    - **Selection**：只读你选中的片段
> 4. **Temperature（创造力）**：事实/总结用 `0.1–0.3`，改写用 `0.5–0.7`，创意发散用 `0.8–1.0`
>
> ⚠️ Vault QA 读不了图片/PDF/音视频，也读不到 Dataview 查询结果——它只认纯文本和 Markdown。

### 三个高频 Prompt（复制即用）

除了对手盘的「攻击」Prompt，这三个日常最常用：

**① 三句话总结**（最快确认一篇笔记讲了什么）

```
请用三句话总结这篇笔记：
第一句：它说的是什么。
第二句：它和什么有关联（链接到我已有的知识）。
第三句：它对我有什么用。
```

**② 费曼理解检查**（用追问逼出你的理解盲点）

```
请扮演一个完全不了解「XXX」的人，对我的解释提出 3-5 个追问，
帮我发现理解盲点。基于我的回答，指出我哪里理解错了。
```

**③ 知识缺口分析**（喂多篇笔记，让 AI 找你没意识到的关联）

```
请扫描以下笔记：[[笔记1]] [[笔记2]] [[笔记3]]
找出它们的共同主题（3-5 个），每个主题涉及哪些笔记，
并建议可以新建什么 MOC（内容地图）。
```
