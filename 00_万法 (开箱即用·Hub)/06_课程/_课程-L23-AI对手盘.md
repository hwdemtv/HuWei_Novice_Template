# L23 | 让 AI 成为你的思维磨刀石

> [!tip] 💡 你将收获
> - 学会使用四级 AI 对手盘 Prompt
> - 把 AI 从「代笔」变成「挑刺专家」
> - 建立自己的 AI 辅助写作工作流

---

## 👀 看：AI 对手盘的四级 Prompt

打开 [[00_万法 (开箱即用·Hub)/01_模板/07_进阶工具箱/模板-AI对手盘Prompt库]]，你会看到四个级别的 Prompt：

| 级别 | 名称 | 干什么 |
|------|------|--------|
| 基础版 | 文章诊断 | 告诉你「读者为什么不想点开」 |
| 进阶版 | 观点攻击 | 用最强逻辑攻击你的观点 |
| 高阶版 | 盲区探测 | 告诉你「你没想到什么」 |
| 日常版 | 快速挑战 | 每次对话后挑出逻辑漏洞 |

> [!note] 💡 课程注释
> AI 最大的价值不是替你写，而是替你**挑刺**。你写了一篇文章，AI 帮你找到盲区、攻击弱点、补上漏洞——这才是「对手盘」的意思。

---

## 🧠 解：AI 的正确打开方式

### ❌ 错误用法

```
你：帮我写一篇关于 XX 的文章
AI：好的，以下是文章...
你：复制粘贴，发布
```

**问题：你没有思考，AI 也没有挑战你。产出的是 AI 的平均水平，不是你的独特观点。**

### ✅ 正确用法

```
你：我有一个观点：「____」，帮我攻击它
AI：好的，以下是三个反驳角度...
你：第 2 个反驳有道理，我去补一个案例
你：修改后再让 AI 检查
```

**这才是「对手盘」——AI 挑战你，你回应挑战，最终产出更坚固的观点。**

### 分工原则

| AI 做   | 你做     |
| ------ | ------ |
| 提供反驳角度 | 决定是否回应 |
| 找出逻辑漏洞 | 决定如何修补 |
| 列举盲区   | 决定哪些重要 |
| 优化措辞   | 决定语气态度 |

**判断权永远在你手上。**

## 🔨 做：用 AI 对手盘优化你的文章

### Step 1｜选一篇你写过的文章

从 `30_三进阶` 或 `20_二旋` 里选一篇。

### Step 2｜用基础版 Prompt 诊断

复制这段 Prompt 到 AI 对话中：

```
请以一个苛刻的读者视角，回答这个问题：

如果你在朋友圈刷到这篇文章，你为什么不想点开？

请从标题、开头、核心观点、实用价值四个维度各指出一个问题。
```

### Step 3｜用进阶版 Prompt 攻击

```
我现在有一个判断：「（粘贴你的核心观点）」

请你完全站在反方立场，用最强的逻辑攻击这个观点。

要求：
1. 不要客气，直接指出漏洞
2. 每个攻击都要给出理由
3. 最后告诉我：这个观点最脆弱的地方在哪？
```

### Step 4｜根据反馈修改文章

把 AI 的攻击当作「质检报告」，逐条回应：
- 有道理的 → 回去补案例/数据
- 没道理的 → 在文章中提前反驳（[[_课程-L11-七阶写作法|HW-DE-MTV 的 E 阶段]]：回应读者质疑）
