## 👀 看：先看看真实的样子

你现在打开的这个仓库，就是一套**已经跑通的知识操作系统**。

它不是一个笔记本。它是一台**把想法变成作品的机器**。

先花 2 分钟，把左侧的 5 个文件夹各点开一遍：

```
📁 00_万法 (开箱即用·Hub)     ← 模板和说明书（你不需要动它）
📁 10_一心 (随手丢·Inbox)     ← 灵感、碎片、待处理的想法
📁 20_二旋 (磨一磨·Lab)       ← 正在整理和加工的笔记
📁 30_三进阶 (出锅了·Output)  ← 写完的、可以发出去的成品
📁 40_四归藏 (存起来·Archive) ← 发过的、归档的、不再看的
```

## 🧠 解：为什么你需要这个

### 大多数人的默认路径

```
经历 → 遗忘 → 重新经历 → 再次遗忘
```

看过很多书，收藏过很多文章，记过很多笔记，做过很多项目。

但一年后回头看，真正留下来的很少。

**问题不是你不努力，而是你的成长路径本身是断的。**

### 高手的路径

```
经历 → 复盘 → 方法论 → 迁移 → 地图 → 系统 → 复利
```

每一次经历都会沉淀成规则。规则变成方法论。方法论跨场景复用。复用中发现连接。连接构成地图。地图放进系统。系统产生输出。输出带来新的经历——然后再次进入循环。

**这就是「互为螺旋」的意思。每一次循环，你都在上升。**

### 这套系统在解决什么

你可能已经拥有足够多的知识。

缺的不是更多输入。

而是一套**让经验不会丢失的系统**。

大多数人的笔记是「仓库」——存进去就再也没人看。

这套系统要帮你建成「地图」——每个知识点都连着其他点，连接越多，理解越深。

> [!quote] 品牌语言
> 经验不会自动变成资产。
> 方法论是经验的 ZIP。
> Skill 是经验的安装程序。
> 系统，是经验开始复利的地方。

## 🔨 做：现在做三件事

### 第 1 件：写下你今天最重要的一件事

在左侧找到 `10_一心 (随手丢·Inbox)`，新建一条笔记，写下：

```
今天最重要的一件事：______
```

写完了？关掉。不用排版。

### 第 2 件：逛逛首页和万法

先点开侧边栏的 [[首页]]，它是你的"控制台"，日常的快捷入口和模板全在这里。

接着点开左侧文件列表里的 `00_万法 (开箱即用·Hub)`，你的弹药库在这里面：
- `01_模板/`（以后新建笔记用的模板）
- `01_模板/06_外部模板库/`（80+ 个进阶模板，用熟了再探索）
- `05_自定义模板库/`（你自己建的模板放这里，别和系统模板混在一起）

### 第 3 件：忽略其他一切

不要碰插件设置。不要研究知识图谱。不要折腾主题。

**先写，再优化。永远先写。**
