## 🔌 一、插件与设置

### Q0｜Obsidian 打不开 / 白屏？

- 更新 Obsidian 到最新版（旧版可能有兼容性问题）
- Windows 用户：尝试关闭硬件加速 → `设置 → 关闭硬件加速`，重启后生效
- 仍不行 → 到官网 [obsidian.md](https://obsidian.md) 下载最新安装包重装

### Q1｜第三方插件商店打不开 / 装不了插件？

国内网络访问 Obsidian 官方插件市场可能失败。两个办法：
1. **挂梯子**重试
2. **手动安装**：去 [Obsidian 插件 GitHub](https://github.com/obsidianmd/obsidian-releases) 搜插件名 → 下载 `main.js`、`manifest.json`、`styles.css` → 放到仓库的 `.obsidian/plugins/插件名/` 文件夹 → 设置 → 第三方插件 → 启用

### Q2｜插件装了但没反应？

- 设置 → 第三方插件 → 确认开关是**开启**（蓝色）
- 找到对应插件，确认右侧开关**已启用**
- 按 `Ctrl+P` 搜插件名，看命令是否在

### Q3｜插件之间冲突 / Obsidian 闪退？

**第一周不要装额外插件。**（L01 铁律）
排查方法：设置 → 第三方插件 → 逐个关闭 → 每关一个重启，定位是哪个插件的问题。通常是新装的某个插件导致。

### Q4｜新建笔记不在 Inbox？

→ 设置 → 文件与链接 → 新建笔记的存放位置 → 选「指定的文件夹」→ 填 `10_一心 (随手丢·Inbox)`
详见 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L01-基础设置|L01 基础设置]] 的「🎯 变」。

## 📋 二、模板与 Templater

### Q5｜Templater 插入模板时光标不自动定位 / 变量没替换？

- 设置 → Templater → 确认 **Template folder location** 填的是 `00_万法 (开箱即用·Hub)/01_模板`
- 确认 **Trigger Templater on new file creation** 已开启（按需）
- Templater 必须先启用，才能解析模板里的自动变量（如光标自动定位、日期自动填充）

### Q6｜找不到「灵感捕获」模板？

- 按 `Ctrl+P` → 输入 `Templater` → 选择 `Templater: Open insert template modal` → 在列表里找
- 列表是空的？回到 Q5 检查模板文件夹路径
- 模板原始文件在 [[00_万法 (开箱即用·Hub)/01_模板/01_输入收集/模板-灵感捕获|这里]]

### Q7｜用模板建的笔记，日期不对？

模板里的日期是创建那一刻填的。如果你想要别的日期，手动改 frontmatter 里的 `created` 字段即可。

## 🔍 三、搜索与链接

### Q8｜搜索框搜不到我的笔记？

- 检查拼写和大小写（搜索默认不区分，但开了「区分大小写」就要注意）
- `path:`、`tag:` 后面的名字要**完全一致**（含中文、括号、空格）
- 详见 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L04-搜索与检索|L04 搜索与检索]]

### Q9｜`[[ ]]` 链接显示成灰色 / 红色？

灰色 = 你链接的笔记**还不存在**。点击它会自动新建。这是「先占坑后填充」的正常用法，不是错误。
红色（带波浪线）= 可能开了「无效链接检测」，说明找不到对应文件，检查文件名拼写。

### Q10｜图谱视图是空的？

- 图谱只显示**有连接的笔记**。如果笔记之间还没用 `[[]]` 链接，图谱就是散点
- 先做 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L05-双向链接与图谱|L05 双向链接与图谱]]，给笔记加链接

## 🗃️ 四、Dataview

### Q11｜首页 / 进度追踪的表格显示成代码，没有变表格？

- 设置 → 第三方插件 → 确认 **Dataview 已启用**
- Dataview 代码块必须是 ``` 三个反引号包裹，且第一行是 `dataview`
- Live Preview（实时预览）/ 阅读模式下会渲染；源码模式下代码块不会渲染

### Q12｜Dataview 查询出来是空的？

- `FROM "文件夹名"` 的名字必须**完全一致**（比如 `10_一心 (随手丢·Inbox)`，括号和空格都要）
- `FROM #标签` 注意标签前要有 `#`
- `WHERE 字段 = "值"` 区分大小写，字段名拼写要对
- 详见 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L25-Dataview入门|L25 Dataview 入门]]

## 📁 五、文件与同步

### Q13｜笔记放错文件夹了，怎么移动？

- 在左侧文件树里**拖拽**到目标文件夹
- 或在笔记里按 `Ctrl+P` → `Move file to` → 选文件夹
- 移动后内部 `[[链接]]` 会自动更新路径

### Q14｜图片粘贴不进去 / 乱放？

→ 设置 → 文件与链接 → 附件的默认存放路径 → 选「指定的文件夹」→ 填 `纳戒`（附件专用文件夹，路径相对于仓库根目录）
详见 [[00_万法 (开箱即用·Hub)/06_课程/_课程-L01-基础设置|L01 基础设置]]。

### Q15｜怎么备份 / 多设备同步？

> [!example] 🔄 五种同步方案速查
> | 方案 | 适合 | 优点 | 注意 |
> |------|------|------|------|
> | **Obsidian Sync**（官方） | 怕麻烦、要省心 | 端到端加密、版本历史、移动端稳 | 付费（约 $4/月起） |
> | **iCloud** | Apple 全家桶（Mac+iPhone） | 原生、免费 | Windows 需装 iCloud for Windows |
> | **OneDrive / 坚果云** | Windows / 跨平台 | 免费、自动同步 | 移动端要配合本地文件夹 |
> | **Obsidian Git** | 会一点技术、要版本管理 | 免费、有历史版本、可回滚 | 需配置，大仓库/图片稍慢 |
> | **Syncthing** | 不想上云、局域网同步 | 免费、P2P、不经服务器 | 两台都开着才能同步 |

新手推荐 **Obsidian Git**（自动备份到 GitHub）或 **iCloud / OneDrive / 坚果云** 同步整个仓库文件夹。

> ⚠️ 多设备同步时**不要同时编辑同一篇笔记**，否则会产生冲突副本（如 `xxx.1.md`）。
> ⚠️ 不要用会自动改文件名的网盘（可能破坏链接）。详见 [[00_万法 (开箱即用·Hub)/🚀 更多玩法|更多玩法]]。
> ⚠️ 用 Git 同步时，把 `.obsidian/workspace`、`.obsidian/cache`、`.trash/` 加进 `.gitignore`（本地状态，不用同步）。

## ⚠️ 七、常见误区（避开这些坑）

> [!warning] 🚫 三大新手陷阱
> | 陷阱 | 表现 | 解药 |
> |------|------|------|
> | **工具党** | 疯狂装插件、反复换工具，就是不写 | 给当前工具 30 天承诺，禁止换 |
> | **收藏癖** | 只收藏不消化，Inbox 堆成山 | 收藏前过「采集三问」（[[00_万法 (开箱即用·Hub)/06_课程/_课程-L03-火种捕获\|L03]]） |
> | **完美主义** | 觉得分类不完美就反复重构，迟迟不动笔 | 先写后整理，写作模式和整理模式分开 |
>
> 💡 **工具是「用」出来的，不是「挑」出来的。** 笔记写出来比分类完美重要 100 倍。
>
> 🎯 一个自检：关掉笔记 1 分钟后，你能说清「它在说什么 / 对不对 / 怎么用」吗？说不清 = 还没消化。

## 🔁 通用排查三步法

遇到任何问题，先走这三步：

1. **重启 Obsidian**（解决 30% 的玄学问题）
2. **检查设置**（80% 是配置路径/开关没对）
3. **看插件是否启用**（第三方插件总开关 + 单个插件开关都要开）
