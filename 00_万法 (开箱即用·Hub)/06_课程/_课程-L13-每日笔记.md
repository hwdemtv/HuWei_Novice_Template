# L13 | 让每一天都成为素材

> [!tip] 💡 你将收获
> - 学会使用每日笔记模板
> - 建立「日记 → 素材 → 内容」的转化链路
> - 连续 5 天记日记，养成每日记录习惯

---

## 👀 看：一天的日记长什么样

打开 [[10_一心 (随手丢·Inbox)/2026-06-06 示例日记|示例日记]]，你会看到每日笔记模板的结构：

```markdown
## 🎯 今日焦点
> 今天只做这一件事，就值了：
- [ ] 最重要的事：______

## 💭 碎碎念
> 任何想法、吐槽、灵感，写这里：

## ⚡ 今日闪念
> 明天要做的事 / 想问别人的问题 / 突然想到的东西
```

三个部分，每个部分不超过 3 行。**一天的日记，2 分钟写完。**

> [!note] 💡 课程注释
> 日记不是文学创作。它的唯一目的是**捕获**——捕获今天的焦点、碎片想法、明天的待办。写完就关，不排版。

---

## 🧠 解：日记是整个系统的连接组织

日记不是独立存在的。它是整个知识操作系统的**连接组织**：

```
今天的日记
  ├─ 💭 碎碎念 里的一句话 → 可能变成一条火种
  ├─ 🎯 今日焦点 的完成情况 → 可能变成一篇复盘
  └─ ⚡ 今日闪念 的一个想法 → 可能变成明天的选题
```

**日记 → 火种 → 草稿 → 文章 → 发布 → 复盘 → 日记**

这就是「互为螺旋」在日常生活中的体现。

### 每日笔记模板的变量

```yaml
date: 2026-06-18
week: 2026W25
```

- `date` — 自动填入今天的日期（Templater 生成，无需手动编辑）
- `week` — 自动填入 ISO 周数（方便后面做周复盘）

## 🔨 做：连续 5 天记日记

### Step 1｜设置 Calendar 插件

确认左侧有 Calendar 面板。如果没有：
1. 设置 → 第三方插件 → 搜索 Calendar → 启用
2. 左侧会出现日历面板
![[日历面板.png]]

### Step 2｜点击今天的日期

在 Calendar 面板上点击今天，自动创建今日日记（已套用模板）。

### Step 3｜填写今日焦点

```
🎯 今天只做这一件事，就值了：
- [ ] 最重要的事：______
```

### Step 4｜随时记录碎碎念

一天中任何想法、吐槽、灵感，打开日记写一句。不需要完整句子，关键词就行。

### Step 5｜睡前写今日闪念

```
⚡ 明天要做的事 / 想问别人的问题 / 突然想到的东西
```

### 坚持 5 天

连续 5 天，每天打开日记，写三个部分。

> [!check] ✅ 验证清单
> - [ ] Calendar 面板已启用
> - [ ] 点击日期能自动创建日记
> - [ ] 日记模板自动套用（有日期变量）
> - [ ] 连续 5 天都有日记记录
> - [ ] 至少有 1 条碎碎念可以变成火种

## 🎯 变：周末整理

每周末花 10 分钟，打开 [[00_万法 (开箱即用·Hub)/01_模板/05_生活应用/模板-周末整理|周末整理模板]]，做三件事：

1. **清空收件箱**：逐条处理 `10_一心` 里的笔记——值得展开的移到 `20_二旋`，不要的移到 `40_四归藏 (存起来·Archive)`
2. **检查加工区**：看看 `20_二旋` 里有没有可以发布的，能发的移到 `30_三进阶`
3. **回顾本周**：这周记了几条笔记？发了几条内容？下周想写什么？
