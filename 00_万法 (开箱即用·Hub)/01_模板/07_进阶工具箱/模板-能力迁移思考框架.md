# 🔄 能力迁移思考框架

> 知识会过期，结构不会。每学到一个新东西，用「迁移三问」判断它值不值得留下。

---

## 迁移三问

```
我学到的东西：____
```

### ① 它背后的结构是什么？

去掉具体内容，留下骨架。

→ ____

### ② 如果把具体场景拿掉，它还剩什么？

抽象到只剩逻辑关系。

→ ____

### ③ 换个领域，它还能不能成立？

试着套到另一个完全不同的场景：

场景 A：____ → 成立 / 不成立，因为____

场景 B：____ → 成立 / 不成立，因为____

场景 C：____ → 成立 / 不成立，因为____

---

## 迁移检验

> 三个问题的答案都是肯定的 → 这个东西有迁移价值，沉淀到你的系统里。
>
> 第三个问题不成立 → 它可能是领域特定知识，知道就好，不必沉淀。

---

## 连接练习

找两个你觉得完全不相关但你已经知道的东西，尝试连接：

```
东西 A：____
东西 B：____

它们的底层结构有什么相似之处？
→ ____

如果用 A 的方法解决 B 的问题，会怎样？
→ ____
```
