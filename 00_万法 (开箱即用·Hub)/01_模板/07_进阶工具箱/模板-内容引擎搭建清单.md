# 🏗️ 内容引擎搭建清单 · <% tp.date.cursor() %>

> 持续输出不靠灵感，靠系统。四层引擎帮你把「偶尔写一篇」变成「持续生产」。

---

## 第一层：火种仓库

> 随时收集灵感，不要等「想写」再找选题。

**火种来源清单**（每天花 5 分钟扫一遍）：

- [ ] 和朋友聊天时的一个观点 → 记下来
- [ ] 刷到一篇文章，不同意某个点 → 记下来
- [ ] 工作中踩了一个坑 → 记下来
- [ ] 读到一句让你停顿的话 → 记下来
- [ ] 有人问了你一个好问题 → 记下来
- [ ] AI 对话里出现了一个意外洞察 → 记下来

**火种记录格式**：

```
日期：____
火种内容：____
为什么它打动我？____
可能和什么主题有关？____
```

## 第三层：模板流水线

> AI 做 0→60，你做 60→95。

**你的分工边界**：

| AI 做 | 你做 |
|--------|------|
| 整理素材 | 判断哪些素材值得用 |
| 生成初稿 | 改写关键段落 |
| 列举观点 | 选择核心观点 |
| 优化措辞 | 决定语气和态度 |
| 提供反驳 | 决定是否回应、如何回应 |

---

## 第四层：数据飞轮

> 每篇文章发布后记录数据，让下一篇写得更好。

```
文章标题：____
发布日期：____
72小时阅读量：____
分享数：____
新关注：____
我的满意度（1-10）：____
下次可以改进的一点：____
```

**飞轮逻辑**：数据告诉你什么有效 → 沉淀到火种仓库 → 下一篇写得更好 → 更好的数据 → 更多沉淀。
