# 🤖 AI 对手盘 Prompt 库

> AI 最大的价值不是替你写，而是替你挑刺。以下 prompt 直接复制到 ChatGPT / Claude / 其他 AI 中使用。

---

## 基础版：文章诊断

```
请以一个苛刻的读者视角，回答这个问题：

如果你在朋友圈刷到这篇文章，你为什么不想点开？

请从标题、开头、核心观点、实用价值四个维度各指出一个问题。
```

---

## 进阶版：观点攻击

```
我现在有一个判断：「____（粘贴你的观点）」

请你完全站在反方立场，用最强的逻辑攻击这个观点。

要求：
1. 不要客气，直接指出漏洞
2. 每个攻击都要给出理由
3. 最后告诉我：这个观点最脆弱的地方在哪？
```

---

## 高阶版：盲区探测

```
我正在写一篇文章，主题是：____

以下是我的大纲：____

请你做三件事：

1. 指出我可能忽略的角度（我没想到的）
2. 指出我可能过度自信的地方（我以为对但未必对的）
3. 指出读者最可能质疑的地方（他们会怎么反驳）

请以「我是你的对手盘，我要帮你把这篇文章变强」的语气来回答。
```

---

## 日常版：快速挑战

每次形成一个重要判断后，花 30 秒丢给 AI：

```
假设你完全不同意这个观点，请反驳：
「____」
```
