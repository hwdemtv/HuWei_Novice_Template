# 🗺️ 知识地图 · <% tp.file.cursor() %>

> 知识不是仓库，是地图。地图上每个点都连着其他点——连接越多，理解越深。

---

## 单点记录

```
知识节点名称：____
日期：<% tp.date.now("YYYY-MM-DD") %>
来源：____

它是什么？（一句话）
→ ____

它和我已知的什么东西有关？
连接 1：____（关系：____）
连接 2：____（关系：____）
连接 3：____（关系：____）

它背后的结构是什么？
→ ____

它的迁移场景：
→ ____
```

---

## 地图连接练习

拿出你已有的 5 个最重要的知识点，画出它们的连接：

```
知识点 1：____
知识点 2：____
知识点 3：____
知识点 4：____
知识点 5：____

连接关系：
1 ↔ 2：因为 ____
1 ↔ 3：因为 ____
2 ↔ 4：因为 ____
（继续连接，直到每个点至少连到另一个点）
```

---

## 仓库 vs 地图自检

问自己：

- [ ] 我的知识是独立存放的，还是互相连接的？
- [ ] 新学的东西，我有没有试着连到已有的知识上？
- [ ] 我能不能用一个知识点去解释另一个知识点？
- [ ] 如果有人问我「你学的XX和YY有什么关系」，我能不能说清楚？
