# HW-DE-MTV 七阶写作模板

> 任何文章，七个阶段，从想法到成稿。

---

## 这是什么

HW-DE-MTV 是一套七阶写作框架，适用于**所有类型的文章**——公众号长文、知识分享、观点表达、复盘总结。

> 不只是小红书爆款文案的工具，而是一种通用的写作思考方式。

---

## 七阶总览

| 阶段 | 英文 | 核心问题 | 作用 |
|------|------|---------|------|
| **H** | Heart 心脏 | 读者会有什么情绪？ | 种下情感种子 |
| **W** | Will 意志 | 读者原有的认知是什么？ | 打破错觉，制造好奇 |
| **D** | Dare 勇气 | 我的核心观点是什么？ | 文章的脊柱 |
| **E** | Evolve 进化 | 读者可能怎么反驳？ | 提前回应质疑 |
| **M** | Manifest 显化 | 读者能带走什么？ | 可执行的框架/步骤 |
| **T** | Transfer 迁移 | 认知发生了什么变化？ | 从"以为A"变成"发现B" |
| **V** | Vault 留白 | 结尾留什么钩子？ | 让读者想看下一篇 |

## 使用方法

### 第一遍：先填 H 和 W

这两个决定读者会不会继续看。

- **H**：前三句能不能让读者产生情绪？
- **W**：有没有打破读者原有的某个认知？

### 第二遍：填 D

这是文章的脊柱。一句话说不清就还没想清楚。

- **D**：核心观点能不能用一句话说清？

### 第三遍：填 M

分享率的关键——没有可带走的东西，读者不会转发。

- **M**：读者看完有没有一个可以直接用的东西？

### 第四遍：回头补 E、T、V

初稿时可以先空着，写完再补。

- **E**：回应读者可能的质疑
- **T**：升华到更大的道理
- **V**：结尾钩子

---

## 自检清单

写完文章后，逐项检查：

- [ ] **H**：前三句能不能让读者产生情绪？
- [ ] **W**：有没有打破读者原有的某个认知？
- [ ] **D**：核心观点能不能用一句话说清？
- [ ] **E**：有没有回应读者可能的质疑？
- [ ] **M**：读者看完有没有一个可以直接用的东西？
- [ ] **T**：读者的认知有没有发生位移？
- [ ] **V**：结尾有没有让人想看下一篇 / 做某个动作？

## 适用场景

| 场景 | HW-DE-MTV 怎么用 |
|------|-----------------|
| 公众号长文 | 完整七阶，每个阶段展开写 |
| 小红书短文 | 七阶压缩成 300-500 字（见「小红书文案炼金术」） |
| 朋友圈观点 | 只用 H + W + D，三句话说清 |
| 复盘总结 | 只用 D + E + M，核心观点 + 反思 + 方法 |
| 知识分享 | 完整七阶，重点放在 M（可带走的框架） |
| 观点表达 | 重点放在 W + D + T，打破认知 → 给出观点 → 升华 |
