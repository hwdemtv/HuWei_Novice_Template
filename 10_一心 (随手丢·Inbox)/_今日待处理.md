# 📋 今日待处理看板

> 📍 **入口**：从 [[首页]] → 快速入口进入，或 Dashboard「时间节奏 → 今日调度」。
>
> 五区流水线的「调度台」。**位置即状态**——笔记按所在区域自动归类，无需手动维护。🔴 该消化 · 🟡 该出锅 · 🟢 本周成果。

```dataviewjs
const inbox = "10_一心 (随手丢·Inbox)";
const lab = "20_二旋 (磨一磨·Lab)";
const output = "30_三进阶 (出锅了·Output)";
const candidate = "10_一心 (随手丢·Inbox)/_候选记忆";
const excludedNames = new Set(["📚我的书架", "📚知识书架", "发布清单"]);
const notUnder = (p, sub) => !p.file.path.includes(sub);
const inInbox = dv.pages(`"${inbox}"`).where(p => notUnder(p, "_候选记忆") && notUnder(p, "周回顾") && !p.file.name.startsWith("_")).array();
const inLab = dv.pages(`"${lab}"`).where(p => !p.file.name.startsWith("_")).array();
const inOutput = dv.pages(`"${output}"`).where(p => !excludedNames.has(p.file.name) && !p.file.name.startsWith("_")).array();
const candidates = dv.pages(`"${candidate}"`).array();

const nowMs = Date.now();
const dayMs = 86400000;
const backlog = inInbox.map(p => ({ p, days: Math.floor((nowMs - p.file.ctime.toMillis()) / dayMs) }))
  .filter(x => x.days >= 3).sort((a, b) => b.days - a.days);
const weekAgo = dv.date("today").minus({ days: 7 });
const recentOutput = inOutput.filter(p => p.file.ctime.toMillis() >= weekAgo.toMillis())
  .sort((a, b) => b.file.ctime.toMillis() - a.file.ctime.toMillis());

const root = dv.container;
root.classList.add("dashboard-shell");
const el = (parent, tag, cls, text) => parent.createEl(tag, { cls, text });
const link = (parent, path, text) => {
  const a = parent.createEl("a", { cls: "internal-link", text });
  a.setAttr("data-href", path); a.setAttr("href", path); return a;
};

// 一眼速览：四张统计卡
const overview = el(root, "section", "overview-panel dashboard-panel");
const statGrid = el(overview, "div", "stat-grid");
[
  ["🔴 该消化", backlog.length, "Inbox 积压 ≥3 天"],
  ["🟡 该出锅", inLab.length, "加工中半成品"],
  ["🟢 本周成果", recentOutput.length, "近 7 天成品"],
  ["📦 待确认", candidates.length, "候选记忆待入库"]
].forEach(([label, value, hint]) => {
  const card = el(statGrid, "div", "stat-card");
  el(card, "span", "stat-label", String(label));
  el(card, "strong", "stat-number", String(value));
  el(card, "span", "stat-hint", hint);
});

// 三栏流水线看板
const board = el(root, "section", "board-panel dashboard-panel");
el(board, "h2", "panel-title", "🗂️ 流水线看板");
const boardGrid = el(board, "div", "board-grid");
const columns = [
  { key: "backlog", title: "🔴 该消化", hint: "超 3 天未流走 · /digest 或拖去 20_二旋",
    items: backlog.slice(0, 8).map(x => ({ path: x.p.file.path, name: x.p.file.name, meta: `🔥 ${x.days} 天 · 捕获于 ${x.p.file.ctime.toFormat("MM-dd")}` })) },
  { key: "lab", title: "🟡 该出锅", hint: "半成品 · 推进到 30_三进阶",
    items: [...inLab].sort((a, b) => b.file.mtime.toMillis() - a.file.mtime.toMillis()).slice(0, 8)
      .map(p => ({ path: p.file.path, name: p.file.name, meta: `${p.type || "加工中"} · 改动于 ${p.file.mtime.toFormat("MM-dd HH:mm")}` })) },
  { key: "done", title: "🟢 本周成果", hint: "近 7 天出锅",
    items: recentOutput.slice(0, 8).map(p => ({ path: p.file.path, name: p.file.name, meta: `${p.type || "成品"} · 发布于 ${p.file.ctime.toFormat("MM-dd")}` })) }
];
columns.forEach(col => {
  const lane = el(boardGrid, "div", `board-column ${col.key}`);
  const head = el(lane, "div", "board-column-head");
  el(head, "h3", "board-column-title", col.title);
  el(head, "span", "board-count", String(col.items.length));
  el(lane, "p", "panel-subtitle", col.hint);
  if (col.items.length === 0) {
    el(lane, "p", "empty-state", "✅ 暂无");
  } else {
    col.items.forEach(it => {
      const card = el(lane, "article", "project-card");
      link(card, it.path, it.name);
      el(card, "span", "project-meta", it.meta);
    });
  }
});
```

## 🧹 建议节奏

| 频率 | 动作 | 命令 |
|------|------|------|
| 每天 | 看一眼🔴积压,挑 1 条消化 | `/digest` |
| 每周 | 批量清掉 Inbox 全部积压 | `/batch-digest` |
| 随时 | 审查候选记忆,确认入库长期记忆 | `/apply-memory` |
| 每周末 | 生成上周回顾 | `/weekly-review` |
| 每周末 | 清理🟡半成品,手动推进出锅 | — |

## 🤖 AI 接入说明

> 上面的 `/命令` **不是 Obsidian 原生功能**,而是 **Claudian(第二大脑 Agent)** 的 AI 技能。在 AI 对话框输入斜杠命令即可调用——看板里 🔴积压的消化、记忆沉淀、周回顾,这些「重活」都能交给 AI 做。

### 三层记忆管线(看板驱动的核心 AI 流程)

```
🔴 一心积压笔记  ──/digest──▶  📦 候选记忆  ──/apply-memory──▶  🧠 长期记忆
(10_一心 原始)               (_候选记忆/)                    (00_万法/08_长期记忆/)
```

> `/digest` 只写候选区,**绝不直接改长期记忆**;每条候选都带来源标注,发现与现有记忆冲突会打 ⚠️ 标记。你审查满意后,再用 `/apply-memory` 确认入库——**Agent 不会静默合并你的记忆**。

### 看板相关命令速查

| 命令 | 作用 | 何时用 |
|------|------|--------|
| `/digest` | 消化**单篇**笔记 → 候选记忆 + 矛盾检测 | 每天挑 1 条🔴处理 |
| `/batch-digest` | **批量**清掉 Inbox 全部积压 | 每周大扫除 |
| `/apply-memory` | 候选记忆 → 长期记忆(你确认后才入库) | 候选区审查后 |
| `/weekly-review` | 生成上周回顾(新增/流转/未消化/矛盾) | 每周末 |

> 📌 **一次性前置**:首次使用建议先跑 `/init-profile` 建立用户画像,AI 会更懂你的偏好与记忆边界。
